# tools/ — 專案工具

| 檔案 | 作用 |
|---|---|
| `make_registry.py` | 產生 `algorithm.xlsx`（8 個工作表：公理與定義／命題引理定理／演算法／等式／樣本上下文／工程內容2名詞對應／開發期缺陷／說明） |

## 為什麼用腳本產生登記表

登記表是工程的「定理及演算法與等式」總帳。用腳本產生可以：
1. 讓登記表與 `docs/B0001-定理體系.md` 的編號**同步**（改文件 → 改腳本 → 重跑）；
2. 讓 CI 能檢查登記表是否過期（重建後與提交版本比對）。

## 依賴

`python3` + `openpyxl`。無其他依賴。

## 接口

`python3 tools/make_registry.py`（於專案根目錄執行，輸出 `algorithm.xlsx`）。
