# B0002 定理體系：交換閉包系統（擬陣）與 Moore 族的上下文實現

> 登記編號：**B0002**　　前置：**B0001**（全局公理伽羅瓦對應）　　狀態：首輪實作完成（R2）
> B0001 的 P7 只把「擬陣／交換公理」登記為註記；B0002 把它兌現：
> 在 B0001 的閉包框架上**追加交換公理 X5**，得到擬陣；並證明/實作
> 「每個 Moore 族都是一個形式上下文 K_ℱ 的公理閉包族」，於是 B0001 的 T1 對擬陣逐字適用。
> 這就是工程內容2 所要求的「**嵌入／提升／結合**」：擬陣不是新體系，而是 B0001 體系的一個**子範疇**。

## 0. 研究對象

B0001 把「公理系統」抽成閉包算子 cl（擴張、單調、冪等）。
**擬陣（matroid）＝在閉包算子上再加一條交換公理**所致的最強正規性。
B0002 的工作有三塊：

1. **公理側**：立 X5（交換公理）、X6（秩公理 R1–R4），並以迴路系統 D-B1 給出第三種等價描述（Whitney 1935）。
2. **定理側**：T5（三公理等價）、T6（平坦格 = 幾何格，Birkhoff）、T7（Moore 實現／提升定理）、T8（可判定性與負控制）。
3. **演算法側**：GF(2) 線性擬陣 → 迴路 → 閉包 → 秩 → 平坦集 → 幾何格檢核 → 上下文實現 → 繼承 B0001 的 A6。

## 1. 定義（Definitions）

**D-B1（迴路系統）** 設 E 為有限基集（|E| = n）。𝒞 ⊆ 2^E ∖ {∅} 稱**迴路系統**，若
- (C1) ∅ ∉ 𝒞；
- (C2) **反鏈**：C₁ ⊆ C₂ ∈ 𝒞 ⟹ C₁ = C₂；
- (C3) **迴路消去**：∀C₁ ≠ C₂ ∈ 𝒞，∀e ∈ C₁ ∩ C₂，∃C₃ ∈ 𝒞 使 C₃ ⊆ (C₁ ∪ C₂) ∖ {e}。

**D-B2（生成閉包／span）** 對 X ⊆ E，定義
　　cl_𝒞(X) := 滿足「∀C ∈ 𝒞： C ⊆ X 或 |C ∖ X| ≥ 2」的最小超集（由迭代 C ↦ C ∪ {e}（當 C∖X = {e}）得到不動點）。
程式對應：`matroid.Matroid::closure`（迴路消去迭代）。

**D-B3（獨立集與秩）** I ⊆ E **獨立** ⟺ I 不含任何迴路成員；秩 r(X) := max{|I| : I ⊆ X 且 I 獨立}。
程式對應：`Matroid::independent`、`Matroid::rank`（貪心，擬陣貪心正確）。

**D-B4（平坦集／flat）** F ⊆ E 稱**平坦** ⟺ cl_𝒞(F) = F。
程式對應：`Matroid::is_flat`、`Matroid::flats`。

**D-B5（幾何格）** 有限格 L 稱**幾何格**若
(i) **原子生成**：每個元素是若干原子（覆蓋底元者）之併；
(ii) **分級**：存在秩函數 ρ 使 x ⋖ y ⟹ ρ(y) = ρ(x)+1；
(iii) **半模**：ρ(x) + ρ(y) ≥ ρ(x ∨ y) + ρ(x ∧ y)。
程式對應：`matroid.check_geometric`（分級、半模、原子生成、Jordan–Dedekind 四項）。

**D-B6（Moore 族與實現上下文）** ℱ ⊆ 2^E 稱 **Moore 族**若 ⋂ 任意子族 ∈ ℱ 且 E ∈ ℱ。
給定 Moore 族 ℱ，定義**實現上下文** K_ℱ := (E, ℱ, ∈)：公理 = E 的元素，陳述 = ℱ 的元素，(e,F) ∈ R ⟺ e ∈ F。
程式對應：`matroid.context_of_moore_family`。

**D-B7（擬陣）** 三元組 M = (E, 𝒞) 並滿足 D-B1 者稱**擬陣**；由 D-B2 得其閉包算子。

## 2. 公理（Axioms，續 B0001）

**X5（交換公理 / Exchange）**
> 對所有 X ⊆ E 與 y, z ∈ E ∖ cl(X)：
> 　**y ∈ cl(X ∪ {z}) ⟹ z ∈ cl(X ∪ {y})。**

**X6（秩公理 R1–R4）**
> (R1) **r(∅) = 0** 且 0 ≤ r(X) ≤ |X|；(R2) X ⊆ Y ⟹ r(X) ≤ r(Y)；
> (R3) **次模** r(X) + r(Y) ≥ r(X ∪ Y) + r(X ∩ Y)；
> (R4) **單位增量** r(X) ≤ r(X ∪ {e}) ≤ r(X) + 1。
> 由 r 反推閉包：**cl_r(X) = { e ∈ E : r(X ∪ {e}) = r(X) }**。
>
> ＊注意（實測修正）＊：R4 **不可**寫成「r({e}) = 1」。擬陣允許**環（loop）**——r({e}) = 0 的元素；
> 只有**無環擬陣**才有 r({e}) = 1。B0002 開發期以隨機 GF(2) 擬陣（含零列、重複列）檢核時，
> 這個過強的寫法立即在 `check_rank_axioms` 失敗，遂改為標準的「r(∅)=0 + 單位增量」形式。

**X7（有限性，承 B0001 X1）** E 有限，故 2^E 可枚舉、交換公理可用 O(2ⁿ·n²) 判定（T8）。

## 3. 命題（Propositions）

**P-B1（閉包四性）** cl_𝒞 擴張、單調、冪等（承 B0001 P2），且 **cl_𝒞(X) = X ⟺ X 為平坦集**。

**P-B2（秩—閉包對偶）** X ⊆ cl(X) 且 r(cl(X)) = r(X)；cl_r(X)（X6 的定義式）等於 cl_𝒞(X)。
*證明.* 標準：r(X∪{e}) = r(X) ⟺ e 由 X 生成（擬陣的交換性使「生成」與「不增秩」等價）。
本登記以「兩條獨立程式路徑（迴路迭代 vs 秩增量）」互相比對，見 A6 檢核 `check_rank_closure_agreement`。

**P-B3（極小相依 = 迴路）** 對任意 X，X 相依 ⟺ 存在 C ∈ 𝒞 使 C ⊆ X。（D-B1 + D-B3 直譯。）

**P-B4（平坦族是 Moore 族）** ℱ(M) := { F : cl(F) = F } 對交封閉且含 E、∅，故為 Moore 族（D-B6）。
*證明.* 若 {F_i} 平坦，則 cl(⋂F_i) ⊆ ⋂cl(F_i) = ⋂F_i（單調），又 ⋂F_i ⊆ cl(⋂F_i)（擴張），故相等。∅ 平坦因 cl(∅) = ∅（無迴路 ⊆ ∅）。E 平坦顯然。∎

## 4. 定理（Theorems）

### T5（**三公理等價**：閉包／迴路／秩，Whitney 1935）
在 E 有限下，下列資料互相唯一決定，且任一的公理成立則另二者亦成立：
1. 滿足 X1 + 交換公理 X5 + 冪等的閉包算子 cl；
2. 迴路系統 𝒞（D-B1）；
3. 滿足 X6 的秩函數 r。
*結構要點*
- 1 ⟹ 2：迴路 := 極小相依集（相依 ⟺ ∃e ∈ X : e ∈ cl(X∖{e})）；交換公理保證 (C3)。
- 2 ⟹ 3：r(X) = |X| ∖（最大可刪去數），或以「消除迴路」貪心定義；次模性由 (C3) 推出。
- 3 ⟹ 1：以 cl_r(X) = {e : r(X∪{e}) = r(X)} 定義，R3 保證交換公理。
＊B0002 不重打全部證明（屬標準結果），而是**把三條路徑都實作出來並互相比對**：
GF(2) 線性擬陣 → 迴路（A13）→ 閉包（A8）→ 秩（A9）→ 閉包（P-B2 反推），
任兩路径不一致即 A6 檢核失敗。＊

### T6（**平坦格 = 幾何格**，Birkhoff）
M 為擬陣 ⟺ 其平坦集族 ℱ(M) 在 ⊆ 下構成幾何格（D-B5）；此時 ρ(F) = r(F)。
**底元是 cl(∅) 而非 ∅**：若 M 有環，∅ 不是平坦集（cl(∅) = 環集），平坦格的底元即環集；
分級性只在底元以上要求，原子 = 秩 1 平坦集。
*證明要點*
- ⟹：分級由 r 的整值性與覆蓋關係 r(F⋖G) = r(F)+1；半模即 R3；原子 = 秩 1 平坦集，原子生成由 r(X) 為 X 中獨立集之極大基數。
- ⟸：幾何格 L 的秩函數誘導 r(X) := ρ(∨_{e∈X} atom(e)) 滿足 X6，故給出擬陣（標準 Birkhoff 定理）。
＊本登記以 A10 實作四項檢核（分級／半模／原子生成／Jordan–Dedekind）於 4 個真擬陣上，並以反例（區間凸包）證明檢核非恆真。＊

### T7（**Moore 實現定理／提升定理**）
設 ℱ ⊆ 2^E 為 Moore 族（D-B6）。則在 B0001 的實現上下文 K_ℱ = (E, ℱ, ∈) 中：
1. Φ(X) = { F ∈ ℱ : X ⊆ F }，Ψ(Y) = ⋂ Y；
2. **cl_A(X) = ΨΦ(X) = ⋂{F ∈ ℱ : X ⊆ F} = ℱ-閉包**；
3. 故 ℱ = ℭ_A（K_ℱ 的公理閉包族），B0001 的 T1 逐字適用：ℭ_A ≅ (ℭ_S)^op 且 |ℭ_A| = |ℭ_S| = |B(K_ℱ)|；
4. 特別地，每個擬陣 M 的平坦族 ℱ(M) 都是某形式上下文的公理閉包族，
   即 **擬陣 ⊆ B0001 體系**（提升／嵌入），擬陣理論的全部閉包結果可在此框架中計算。
*證明.* Φ(X) 是 D2 的定義；Ψ(Y) = {e : ∀F∈Y, e∈F} = ⋂Y（交在 ℱ 中閉合）；故 ΨΦ(X) = ⋂{F ⊇ X}，正是 Moore 閉包。第 3 點由 B0001 T1／P3／P4 直接適用。∎
＊注意（T2 的教訓）*：K_ℱ 一般**不滿足 X3 分離性**（例如 M(K₃) 的三條邊有相同的 row），
故 B0001 的 T2 會報告冗餘公理 —— 這不是缺陷，而是「實現上下文不是極小公理基」的正確診斷。

### T8（**可判定性與負控制**）
1. 給定任意閉包算子（以黑箱 oracle 表示），X5 是否成立可在 O(2ⁿ·n²) 內判定；
2. 不滿足 X5 的閉包**不可能**由任何迴路系統表示（T5 的逆否），
   例如 {0,…,m−1} 上的**區間凸包**（antimatroid）違反 X5：
   取 X = {0}, y = 1, z = 2（m ≥ 3）：cl(X ∪ {z}) = cl({0,2}) = {0,1,2} ∋ y，但 cl(X ∪ {y}) = cl({0,1}) = {0,1} ∌ z。
   （此即 A14 在樣本 `interval-4` 上實際回報的最小反例。）
3. 因此 A6 檢核器的 `check_exchange` **不是恆真綠燈**：它必須在負控制樣本上 FAIL 才算有效。
程序對應：`matroid.check_exchange`、`matroid.interval_closure`（負控制）、樣本 `interval-4`。

## 5. 演算法（Algorithms）

| 編號 | 名稱 | 依據 | 輸入 → 輸出 | 複雜度 | 落點 |
|---|---|---|---|---|---|
| A8 | `closure`（迴路消去） | D-B2、P-B1 | (M, X⊆E) → cl(X) | O(\|𝒞\|·n·\|cl(X)\|) | `matroid/matroid.mbt` |
| A9 | `rank` / `independent`（貪心） | D-B3、P-B2 | (M, X) → r(X) | O(n·\|𝒞\|·n) | 同上 |
| A10 | `flats` + `check_geometric` | T6 | M → 平坦族、幾何格四項 | O(2ⁿ·closure + \|ℱ\|²·closure) | `matroid/flats.mbt` |
| A11 | `context_of_moore_family` / `moore_family_of_context` | T7 | ℱ → K_ℱ；K → ℭ_A（互逆檢核） | O(\|ℱ\|·n) | `matroid/realize.mbt` |
| A12 | `matroid_report`（擬陣檢核＋B0001 A6 繼承） | T5–T8 | M → 檢核報告 | 見各檢核 | `matroid/checks.mbt` |
| A13 | `circuits_from_gf2`（GF(2) 線性擬陣） | T5(2⟸mat) | GF(2) 列向量 → 秩、獨立、迴路 | O(2ⁿ·n·m/64) 求迴路；O(n·m/64) 求秩 | `matroid/gf2.mbt` |
| A14 | `check_exchange`（交換公理反例搜尋） | X5、T8 | 閉包 oracle → PASS/FAIL + 反例 | O(2ⁿ·n²) | `matroid/checks.mbt` |

**設計要點**
1. GF(2) 線性擬陣用位元字組做高斯消去（秩 O(n·⌈m/64⌉)），並以「基數遞增 + 極小相依」抽迴路（A13）——
   於是 `Fano ≅ PG(2,2)` 與 `圖擬陣 M(K_n)` 都可由**同一個**引擎產生，無需手寫迴路表。
2. 平坦集用兩條路徑計算：(a) 迴路消去閉包逐子集判定；(b) 由 A11 建出 K_ℱ 後用 B0001 的 NextClosure 枚舉。
   兩者必須一致 → `check_flats_agree_with_context`（A6 常設檢核）。
3. 幾何格四項檢核必須在**負控制**上失敗，否則視為檢核失效（T8.3）。

## 6. 等式（Equalities，續 B0001）

- **E-B1** cl_𝒞(X) = X ⟺ X 平坦（P-B1）
- **E-B2** r(X) = r(cl(X))，cl_r(X) = {e : r(X∪{e}) = r(X)}（P-B2）
- **E-B3** X 相依 ⟺ ∃C ∈ 𝒞, C ⊆ X（P-B3）
- **E-B4** ℱ(M) 為 Moore 族（P-B4）
- **E-B5** ρ(F) = r(F)，且 F ⋖ G ⟹ r(G) = r(F)+1（T6 分級）
- **E-B6** r(F)+r(G) ≥ r(F∨G)+r(F∧G)，F∨G = cl(F∪G)、F∧G = F∩G（T6 半模）
- **E-B7** cl_A^{K_ℱ}(X) = ⋂{F ∈ ℱ : X ⊆ F}（T7.2）
- **E-B8** 圖擬陣：|ℱ(M(K_m))| = B_m（Bell 數）——K₃: 5、K₄: 15（可執行見證）
- **E-B9** Fano：|𝒞| = **14** = 7 條線（3 元）+ 7 個線補集（4 元）、|ℱ| = 16、r(E) = 3
  （線補集是最小相依集：PG(2,2) 中每條線與給定線必相交，故線補集內無線 ⇒ 4 元迴路）
- **E-B10** U(r,n)：𝒞 = 所有 (r+1)-子集，|ℱ| = 1 + n + 1（r=2 時）

## 10. 二元性與正則性（T9）

### 10.1 定義

**D-B8（minor）** 對 e ∈ E：
- 刪除 M∖e：地面集 E∖{e}，迴路 = M 中不含 e 的迴路；
- 壓縮 M/e：地面集 E∖{e}，迴路 = {C∖{e}} 的極小非空成員。
程式一律以**秩**為唯一真相來源：minor M/D.C 的秩 r'(X) = r_M(X ∪ C) − r_M(C)（X ⊆ E∖(D∪C)），
再由秩函數取極小相依集作迴路。這樣就避開表示法陷阱（定理只談秩）。

**D-B9（二元／正則）**
- M **二元**（binary）：存在 GF(2) 上的 r×n 矩陣其向量擬陣為 M。
- M **正則**（regular）：M 可在**任意**體上表示（等價：有 ℤ 上全么模表示）。

### 10.2 命題

**P-B5（基本迴路釘住 GF(2) 表示）** 設 B 為 M 的基。若 M 二元，則其在同構意義下的 GF(2) 表示唯一，
且對每個 e ∉ B，**基本迴路** C(B,e)（⊆ B∪{e} 且含 e 的極小相依集）決定 col(e) = Σ_{b∈C∖{e}} col(b)
（GF(2) 中迴路上和為零，而最小相依 = 唯一最小相依）。
*推論*：可由基 + 基本迴路**顯式構造** GF(2) 表示並驗證；若驗證失敗則 M 必非二元。

**P-B6（餘迴路 = 超平面的補集）** M* 的迴路（= M 的餘迴路）恰為 E∖H，H 跑遍 M 的超平面（秩 r(E)−1 的平坦集）。

**P-B7（對偶平坦集的秩判準）** X 是 M* 的平坦集 ⟺ ∀ e ∈ E∖X：r_M(E∖X) = r_M(E∖X∖{e})。
（由 r*(X) = |X| − r(E) + r(E∖X) 直接代入平坦定義。）

### 10.3 定理

**T9（Tutte 1958，二元禁 minor 判準）** M 二元 ⟺ M 沒有同構於 **U(2,4)** 的 minor。

> ＊開發期重大修正（DOC-3）＊ 我原先的草稿寫「二元 ⟺ 無 {U(2,4), F7, F7*} minor」，那是**正則**的判準。
> **Fano 擬陣 F7 = PG(2,2) 本身是二元擬陣**——它就是 GF(2)³ 的 7 個非零向量；F7 不是**正則**擬陣。
> 把 F7 放進二元禁集會把 Fano 判成非二元。檢核器（`check_fano_binary_not_regular`）就是為了釘死這一條。

**T9′（Tutte 1958，正則禁 minor 判準）** M 正則 ⟺ M 沒有同構於 U(2,4)、F7、F7* 的 minor。
推論：正則 ⇒ 二元（逆不成立，F7 為反例）；圖擬陣、餘圖擬陣皆正則（關聯矩陣在 ℤ 上全么模，正則性對偶封閉）。

### 10.4 驗證（兩條完全獨立的路徑）

| 樣本 | 禁 minor 判準 | 基本迴路構造 | 一致 | 正則 |
|---|---|---|---|---|
| U(2,4) | 非二元（含 U(2,4)） | 非二元（基本迴路缺失） | ✓ | 否 |
| M(K3)、M(K4) | 二元 | 二元 | ✓ | 是（含對偶） |
| Fano (F7) | 二元 | 二元 | ✓ | **否**（含 F7 minor） |
| Fano* | 二元 | 二元 | ✓ | 否 |
| U(3,5) | 非二元 | 非二元 | ✓ | 否 |
| M(K4)* | 二元 | 二元 | ✓ | 是 |

普查（n = 5）：**406 個擬陣上兩條路徑 0 次分歧**；n = 4 的唯一非二元／非正則擬陣是 U(2,4)（與 T9 一致）。

## 11. 對偶擬陣（T10）

**D-B10（對偶）** r*(X) = |X| − r_M(E) + r_M(E∖X)；M* = (E, 𝒞(M*))，其中 𝒞(M*) 為 r* 下的極小相依集。

**T10（對偶的結構定理，全部在程式內逐項檢核）**
1. (M*)* ≅ M（對全部子集逐點比對秩）。
2. 餘迴路 = 超平面的補集（P-B6），成對比較。
3. 對偶平坦集的秩判準（P-B7），對全部 2^n 個 X 比對。
4. U(r,n)* ≅ U(n−r,n)。
5. **Tutte 對偶**：T_{M*}(x,y) = T_M(y,x)（逐係數）。
6. M(K₄)* ≅ M(K₄)（K₄ 是自對偶平面圖）⇒ 兩者 |ℱ|、|𝒞| 相同。

> ＊開發期修正（THM-1）＊ 我曾據「平坦格對偶」寫下 |ℱ(M*)| = |ℱ(M)|，**這是錯的**：
> M = U(2,3) 有 5 個平坦集，其對偶 U(1,3) 只有 2 個。正確的可用關係是上面的 P-B7 判準
> （以及 M(K₄) 這種自對偶個案）。Fano* 的平坦數 44 因此**不設「期望值」**（登記表以 −1 標記「無獨立公式」），
> 只用結構定理檢核，絕不以程式自己算出的數當期望值（否則是循環論證）。

## 12. Tutte 多項式與特徵／色多項式（T12）

**D-B11（Tutte 多項式）** 兩條等價定義：
- 刪除–壓縮：T = 1（無元素時）；迴路 e ⇒ T = y·T(M∖e)；橋 e ⇒ T = x·T(M∖e)；
  否則 T = T(M∖e) + T(M/e)。
- 子集和：T(x,y) = Σ_{A⊆E} (x−1)^{r(E)−r(A)} (y−1)^{|A|−r(A)}。

**P-B8** 兩條定義給出同一個多項式（程式以兩路徑逐係數相等檢核）。

**T12（特化與跨物件一致）**
1. T(1,1) = 基數；T(2,1) = 獨立集數；T(1,2) = 生成集數；T(2,2) = 2^{|E|}。
2. 特徵多項式兩路徑：χ(λ) = Σ_A (−1)^{|A|} λ^{r(E)−r(A)} 與 χ(λ) = (−1)^{r(E)} T(1−λ, 0) 相同。
3. **Whitney**：圖 G 的著色多項式 P(G,λ) = λ^{c(G)}·χ_{M(G)}(λ)（c = 連通分量數）。
   ＊修正（THM-2）＊ 首版漏掉 λ^{c(G)} 因子，K₃ 在 λ=3 上得 χ=2 而著色數 6，檢核器立刻紅燈。
4. Fano 的經典結果：χ_{F7}(λ) = (λ−1)(λ−2)(λ−4) = λ³ − 7λ² + 14λ − 8（根為 2 的冪）。

實測值（全部由程式算出，兩條路徑逐係數相同；以下為 `mext` 的實際輸出）：

| 擬陣 | T_M(x,y) | χ_M(λ) |
|---|---|---|
| U(2,4) | x² + 2x + y² + 2y | λ² − 4λ + 3 (= (λ−1)(λ−3)) |
| M(K₃) | x² + x + y | λ² − 3λ + 2 (= (λ−1)(λ−2)) |
| M(K₄) | x³ + 3x² + 4x + 2xy + 3y² + y³ + 2y | λ³ − 6λ² + 11λ − 6 (= (λ−1)(λ−2)(λ−3)) |
| F7 | x³ + 4x² + 3x + 7xy + 6y² + 3y³ + y⁴ + 3y | λ³ − 7λ² + 14λ − 8 (= (λ−1)(λ−2)(λ−4)) |
| F7* | x⁴ + 3x³ + 6x² + 3x + 7xy + 4y² + y³ + 3y | λ⁴ − 7λ³ + 21λ² − 28λ + 13 |
| M(K₄)* | x³ + 3x² + 4x + 2xy + 3y² + y³ + 2y | λ³ − 6λ² + 11λ − 6 |

一致性見證：T_{F7}(x,y) 與 T_{F7*}(y,x) 互為交換 ✓（T10 第 5 條）；T(K₄) 與 T(K₄*) 相同 ✓（自對偶）；
T(1,1) = 基數（K₄：16 棵生成樹）、T(2,1) = 獨立集數（K₄：38 = 1+6+15+16）、χ_{F7} 的三根為 1,2,4 ✓。

## 13. 均勻擬陣的平坦計數與小型擬陣普查（T11、A19）

**T11** |ℱ(U(r,n))| = 2 + Σ_{k=1}^{r−1} C(n,k)（0 < r < n）。
理由：平坦集恰為 ∅、所有 1 ≤ k ≤ r−1 的 k-子集、以及 E（r-子集都被閉成 E）。
邊界：r ≥ n ⇒ Boolean 格 2^n；r = 0 ⇒ 只有 E（全部是環）。

> ＊開發期修正（THM-3）＊ 草稿寫成 Σ_{k≤r} C(n,k)，U(1,2) 就紅燈（實得 2，公式給 3）。
> 正確是「少一層再 +1」的形式。

**T11′（普查：兩條公理系統的計算版 T5）** 以 C1–C3（迴路）與 I1–I3（獨立集）兩條完全不同的路線
列舉 n 元素上的全部擬陣，計數必須相同：

| n | 迴路路線 | 獨立集路線 | 同構類 | 非二元 | 非正則 |
|---|---|---|---|---|---|
| 2 | 5 | 5 | 4 | 0 | 0 |
| 3 | 16 | 16 | 8 | 0 | 0 |
| 4 | 68 | 68 | 17 | **1（= U(2,4)）** | 1 |
| 5 | 406 | 406 | 38 | 32（6 個同構類） | 32 |

n = 3 的 16 可用手算核對（空族 1 + 環集 8 + 對集 3 + 三元迴路 1 + 環加平行對 3 = 16）；
n = 4 的唯一非二元擬陣同構於 U(2,4)——正是 T9 的預言。
