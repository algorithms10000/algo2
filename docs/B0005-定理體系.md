## 0. 這一輪要回答的問題

`工程內容2.md` 的名詞群裡還有兩條沒有落地：**「拓撲辮群」**與**「雅可比簇群分」**。
本輪把它們做成兩件**可執行**的東西，並且——這是關鍵——讓它們**不只自成一格，而是接到既有的 B0001–B0004 上**：

> **問題一（辮群）**：B0003 的 Γ(n) = ker(SL₂(ℤ) → SL₂(ℤ/n)) 到底是「什麼的核」？
> 答案：**B_3 ↠ PSL₂(ℤ) → PSL₂(ℤ/n)** 這條滿射的合成核（**T24**）。B_3 的中心 ⟨(σ₁σ₂)³⟩
> 正好落在 ±I 上，於是 B_3 → PSL₂(ℤ) 是「模掉中心」的滿射。

> **問題二（雅可比簇）**：代數曲線 C 的雅可比簇 J(C) = Pic⁰(C) 不可直接計算。
> 本輪採用**組合模型**：圖 G 的沙堆群 J(G) = ℤ^V / im L。
> 在這個模型上，「\|J\| 是生成樹個數」（T25）、「J(K_n) ≅ (ℤ/n)^{n−2}」（T26）、
> 「Riemann–Roch 障礙 r(D) − r(K−D) = deg D − g + 1」（T28）、
> 「theta 特徵的 Arf 計數 2^{g−1}(2^g ± 1)」（T29）**全部變成可以被程式否證的等式**。

兩件之間的接縫是**同一個代數骨架**：辮群給出**非交換的**置換層，雅可比簇給出**交換的**不變量層；
Burau 表示是「非交換 → 線性」，J(G) 的不變因子是「交換 → 有限群」。§10 逐一交代本輪用到的二十個動詞，
§11 交代十四式組合範例各自的落點。

## 1. 公理與定義

### 1.1 公理（本輪新增，全部由檢核器落實）

**A-B1（表現公理）** 群的「表現」是多項式資料：生成元的有限字集合，模兩類關係（交換、辮）。

**A-B2（精確性公理）** 辮群的線性表示必在 **ℤ 或 ℤ[t^{±1}] 上精確計算**，不得用浮點或模某個多項式的近似；
「相等」必須是「多項式係數逐一相等」。

**A-B3（有界陳述公理）** 對「是否忠實」這類**不可窮舉**的性質，只允許作出**帶界限的陳述**：
「長度 ≤ L 內無偽核」必須在輸出裡寫出 L 的具體值，不得寫成「Burau 是忠實的」。

**A-J1（同構不變公理）** 雅可比簇的結論必以**不變量的形式**陳述（階、不變因子、2-秩、Arf），
不得以某一個特定的生成元矩陣的形式陳述。

**A-J2（三路徑公理）** 任何一條計數定理（τ = \|J\|）至少要有**兩條彼此獨立的計算路徑**同時通過，
方可在 `algorithm.xlsx` 登記；本輪的 τ 有三條（行列式、暴力、刪縮）。

### 1.2 辮群的定義

**D-B1（辮群）** B_n = ⟨σ₁, …, σ_{n−1} | σ_iσ_j = σ_jσ_i（\|i−j\| ≥ 2）、σ_iσ_{i+1}σ_i = σ_{i+1}σ_iσ_{i+1}⟩。
程式表示：`BraidWord { n, letters }`，`letters[i]` 為正數表 σ_i、負數表 σ_i^{−1}（零不用）。

**D-B2（純辮群）** P_n = ker(π) = 核。

**D-B3（置換商）** π: B_n → S_n，π(σ_i) = (i, i+1)（`transposition(i, i+1)`），
由「關係在 S_n 中成立」保證 π 是同態（`permutation_braid_relation`）。

**D-B4（Burau 表示）** 未約化 Burau β_n: B_n → GL_n(ℤ[t^{±1}])：

```
β_n(σ_i) = I_{i−1} ⊕ [ 1−t  t ]  ⊕ I_{n−i−1}
                      [  1   0 ]
```

程式以 `LPoly`（Laurent 多項式：指數可負、BigInt 係數、規範形）＋`LMat` 精確實作。

**D-B5（B_3 的模群表示）** σ₁ ↦ T = [[1,1],[0,1]]，σ₂ ↦ S T S = [[−1,0],[1,−1]]（S = [[0,−1],[1,0]]）。
在 PSL₂ 的意義下（差 ±I）比較，即 `mat2_same_pm`。

**D-B6（有界偽核搜索）** `burau_fake_kernels(n, L)`：長度 ≤ L 的全部字中，Burau 像為單位矩陣的**非空**字個數。

### 1.3 雅可比簇的定義（圖的沙堆群模型）

**D-J1（圖）** G = (V, E)，\|V\| = n，允許多重邊；`Graph { n, edges }`。

**D-J2（Laplacian）** L = D − A，L_{vv} = deg v、L_{uv} = −(\#\{u,v\})。

**D-J3（雅可比簇）** J(G) = ℤ^V / im(L)，即圖的臨界群／沙堆群。

**D-J4（不變因子）** 由 Smith 正規形 J(G) ≅ ⊕_{i=1}^{n−1} ℤ/d_i，d₁ \| d₂ \| … \| d_{n−1}。
本輪用**子式 gcd 版**：g_k = gcd(全部 k×k 子式)，d_k = g_k / g_{k−1}（BUG-11）。

**D-J5（除子）** 除子 D: V → ℤ，deg D = Σ D(v)。線性等價 D ~ D′ ⟺ D − D′ ∈ im(L)。
**有效等價** `eff(D)`：存在 E ≥ 0 且 deg E = deg D 使 D − E ∈ im(L)（即 D 的等價類裡有有效除子）。

**D-J6（除子秩與典範除子）** r(D) ≥ k ⟺ 對所有 F ≥ 0、deg F = k，都有 eff(D − F)。
K = Σ_v (deg v − 2)·v（`canonical_divisor`）。虧格 g = \|E\| − \|V\| + 1。

**D-J7（二次細化與 Arf）** J[2] ≅ 𝔽₂^{2g}，Weil 配對 e₂ 是**非退化交錯**形式 ⟨·,·⟩。
二次細化 q: J[2] → 𝔽₂ 滿足 q(x+y) = q(x) + q(y) + ⟨x,y⟩；本輪取 q = q₀ + ℓ，
q₀(Σa_i e_i + Σb_j f_j) = Σ a_i b_j。Arf(q) = Σ_i q(e_i)q(f_i)（`arf_invariant`）。

## 3. 定理 T22（計算機抽象／共性：B_n ↠ S_n 且像為全對稱群）

> **T22**　對 n ≥ 2，π: B_n → S_n 是滿射；⟨σ₁, …, σ_{n−1}⟩ 在 S_n 中生成 S_n，
> 故 \|im π\| = n!，且 P_n = ker π 的指數 = n!。

**證明要點**：π(σ_i) = (i, i+1) 是相鄰對換，而相鄰對換生成 S_n（歸納：把 n 用 (n−1, n), (n−2, n−1), …, (1,2) 移到最右）。
滿射性由 P-B1（π 良定義）＋生成性得出；指數 = \|S_n\| = n!。

**檢核**（`check_permutation_quotient`，n = 2..6）：
BFS 從 id 出發、用 {π(σ_i)} 做生成閉包，比較 \|閉包\| 與 `factorial(n)`；同時驗兩類辮關係在 S_n 層的精確等式。

| n | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|
| \|im π\| = n! | 2 | 6 | 24 | 120 | 720 |

**要點**：這是**計算機抽象**的落地——把「辮的拓撲」抽象成「位置的置換」，只保留 B_n 的有限商。

## 4. 定理 T23（衍生／計算：Burau 是表示，且行列式是乘法指標）

> **T23**　(a) β_n 是同態：β_n(σ_iσ_{i+1}σ_i) = β_n(σ_{i+1}σ_iσ_{i+1}) 且（\|i−j\| ≥ 2 時）
> β_n(σ_i)β_n(σ_j) = β_n(σ_j)β_n(σ_i)，在多項式環 ℤ[t^{±1}] 上**逐係數精確**成立。
> (b) det β_n(σ_i) = −t ⇒ det β_n(w) = (−t)^{exp(w)}。
> (c) 對 n = 2, 3 與長度 L = 6，非空字的 Burau 像**沒有一個**是單位矩陣（有界陳述，見 A-B3）。

**證明要點**：(a) 直接矩陣乘開（2×2 區塊的 t-恆等式）。(b) det([[1−t,t],[1,0]]) = 0 − t = −t。
(c) 窮舉 \{σ_i^{±1}\}^L。

**檢核結果**：
- (a) n = 2..6 全 PASS（`check_burau_representation`）；
- (b) n = 3 的 1/2/3 字母字、n = 4 的 4 字母字全 PASS（`check_burau_determinant`）；
- (c) `burau_fake_kernels(2,6) = 0`、`burau_fake_kernels(3,6) = 0`。

**誠實界限**（A-B3）：本輪**不主張** β_n 忠實。文獻上 reduced Burau 在 n ≥ 4 已知不忠實（Moody 的偽核元素），
所以「長度 ≤ 6 內無偽核」不是忠實性定理，只是對本輪所有後續推論（行列式、模群接縫）足夠弱的假設。
這一條寫進 `algorithm.xlsx` 的「界限欄」。

## 5. 定理 T24（嵌入／併攏：B_3 → PSL₂(ℤ) → PSL₂(ℤ/n)，即 B0003 的 Γ(n) 的源頭）

> **T24**　令 T = [[1,1],[0,1]]、σ₁ ↦ T、σ₂ ↦ S T S。
> (a) 這兩者滿足 B_3 的辮關係（在 PSL₂ 意義下，即差 ±I）；
> (b) (σ₁σ₂)³ ↦ −I，即 B_3 的中心 ⟨(σ₁σ₂)³⟩ 落在 ±I 上；
> (c) 對 n = 2..12，⟨T, STS⟩ 在 SL₂(ℤ/n) 中的影像生成**整個** SL₂(ℤ/n)。
> 合起來：**B_3 ↠ PSL₂(ℤ) ↠ PSL₂(ℤ/n)**，而 ker(B_3 → PSL₂(ℤ/n)) ⊃ ⟨(σ₁σ₂)³⟩，
> B0003 的 Γ(n) = ker(SL₂(ℤ) → SL₂(ℤ/n)) 正是這條滿射在 PSL₂ 層的核。

**證明要點**：(a) T·(STS)·T = (STS)·T·(STS) 直接乘開；(b) (σ₁σ₂)³ ↦ −I（手算 2×2）；
(c) T 與 STS 生成 SL₂(ℤ/n)：STS = [[−1,0],[1,−1]]，配上 T 做行／列運算可達所有初等矩陣，
而 SL₂(ℤ/n) 由初等矩陣生成（n 任意）。

**檢核結果**：`check_b3_to_psl` PASS；`check_b3_image_generates(n)` n = 2..12 全 PASS
（以模 n 的矩陣做 BFS 閉包，比較 \|閉包\| 與 \|SL₂(ℤ/n)\|）。

**併攏的意義**：B0003 的 ψφn = [SL₂ : Γ(n)]、ψ = [SL₂ : Γ₀(n)]、ψφ = [SL₂ : Γ₁(n)] 三條指數公式，
現在有了「**B_3 的滿射鏈**」這個來源；B0004 的 E[n] 辛基計數，則是同一條鏈上的**模 n 自同構群**作用。
三輪（B0003／B0004／B0005）在同一個鏈上對齊。

## 6. 定理 T25（多合一：|J(G)| = τ(G)，三條獨立路徑）

> **T25**　對連通的 G，\|J(G)\| = τ(G)（生成樹個數）。

**證明要點**：Matrix–Tree 定理給 τ = 任一座標主餘子式的行列式；另一方面 J(G) ≅ ℤ^{n−1}/L̃ℤ^{n−1}（L̃ 為約化
Laplacian），其階 = \|det L̃\| = τ。兩邊都是**不變量**（A-J1），故不限於特定座標。

**檢核**（`check_jacobian_order`，7 個樣本）：三條路徑給出同一個數。

| K₄ | 4 | 6 | 3 | 16 | (1, 4, 4) |
| K₅ | 5 | 10 | 6 | 125 | (1, 5, 5, 5) |

## 7. 定理 T26（結構：J(K_n) ≅ (ℤ/n)^{n−2}，並與外部 SNF 逐一比對）

> **T26**　(a) J(K_n) ≅ (ℤ/n)^{n−2}（n ≥ 3）。
> (b) 對 7 個樣本，本輪算出的不變因子與**以標準 Smith 正規形另算**的登記值完全一致。
> (c) \|J[2]\| = ∏ gcd(d_i, 2)，且 \|J[2]\| 整除 2^{β₁}，但**一般不相等**。

**證明要點**：(a) K_n 的 Laplacian = nI − J（J 為全 1 矩陣）；在 ℤ^n/⟨1⟩ 上 nI − J ≡ nI，
故 J(K_n) ≅ (ℤ/n)^{n−1}/⟨1⟩ ≅ (ℤ/n)^{n−2}。(c) 對 ℤ/d 而言 2-撓部分為 ℤ/gcd(d,2)。

**登記值**（外部，標準 SNF）：K₃=(1,3)、K₄=(1,4,4)、K₅=(1,5,5,5)、C₄=(1,1,4)、C₅=(1,1,1,5)、θ=(3)、蝴蝶結=(1,1,3,3)、Q₂=(1,1,4)、Q₃=(1,1,1,1,2,8,24)。全部 PASS。

**BUG-7 的教訓**：K₄ 的 β₁ = 3 但 \|J[2]\| = 4 ≠ 8。所以「J[2] ≅ H₁(G; 𝔽₂)」式的等式**不能**當定理用；
本輪把它降級為 P-J4 的不等式（整除），並在報表明寫「此圖嚴格小於」。

## 8. 定理 T27（推論／否證：圈秩的兩條正確路徑，與一條*錯誤*路徑）

> **T27**　β₁(G) = \|E\| − \|V\| + c = \|E\| − rank_ℚ(L)。（c 為連通分量數）
> **同時證僞**：把 rank_ℚ(L) 換成 rank_{𝔽₂}(L) **不成立**。

**證明要點**：rank_ℚ(L) = n − c（連通時 = n−1）；而 L mod 2 可能退化（奇度頂點在 𝔽₂ 上「消失」）。
C₅：rank_ℚ = 4 而 rank_{𝔽₂} = 1。

**檢核**：7 個樣本上 \|E\| − \|V\| + c = \|E\| − rank_ℚ(L) 全 PASS；報表同時印出 rank_{𝔽₂}(L) 以展示差距。

這一條是本輪**最有教學價值**的一條：一個看起來「都是線性代數」的替換，被最小反例（C₅）當場否掉。

## 9. 定理 T28–T31（衍生：Riemann–Roch、Arf、刪縮、超立方體）

> **T28（Riemann–Roch）**　對任意除子 D：r(D) − r(K − D) = deg D − g + 1，其中 g = \|E\| − \|V\| + 1。
> 檢核：在 K₃、C₄、θ、K₄ 上**枚舉全部** deg ≤ 3（含負座標）的 D，違反者 0。

> **T29（theta 特徵／Arf）**　(a) q = q₀ + ℓ 是二次細化 ⟺ q(x+y) + q(x) + q(y) = ⟨x,y⟩ 對所有 x, y 成立。
> (b) 細化的個數按 Arf 分組：\#\{Arf = 0\} = 2^{g−1}(2^g + 1)、\#\{Arf = 1\} = 2^{g−1}(2^g − 1)。
> (c) Arf 在 Sp_{2g}(𝔽₂) 的拉回下不變。
> 實測：g=1 → 3 / 1；g=2 → 10 / 6；g=3 → 36 / 28，全部吻合；Sp 不變性對 g = 1, 2 **全部**矩陣枚舉通過。

> **T30（刪縮）**　τ(G) = τ(G−e) + τ(G/e)；7 個樣本上與 T25 的三條路徑同值。
> 這是 τ 的**加法**表述，與行列式的**乘法**表述對偶（§11 第 5 式）。

> **T31（超立方體網絡）**　Q_n（2ⁿ 個頂點、差一位元者相連）：
> τ(Q₂) = 4、τ(Q₃) = 384、τ(Q₄) = 42 467 328（對外部登記值）；
> 不變因子 Q₂ = (1,1,4)、Q₃ = (1,1,1,1,2,8,24)；Q₂、Q₃ 另以刪縮遞迴互印。
> **界限**：Q₄ 的 16×16 Laplacian 走子式 gcd 會爆（C(32,16) 個子式），故 Q₄ 只走行列式路徑（BUG-12）。
