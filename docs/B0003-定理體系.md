## 0. 為什麼是這一組

`工程內容2.md` 的名詞群列出「**射影模群 PSL₂(ℤ)**」與「**主同餘子群 Γ(n)、Γ₀(n)、Γ₁(n)**」。
B0001 已把「子群 ↔ 中間體」的伽羅瓦對應做成可執行框架；B0003 換上**真的一組子群**：
同餘子群。它們的優點是

1. 每個 Γ 都由**有限資料**（模 N 的同餘條件）決定，因此「包含、指數、正規性」都能在有限群
   SL₂(ℤ/N) 上**暴力判定**——這給了封閉公式一個完全獨立的對照；
2. 這一族有古典的解析不變量（尖點數、橢圓點數、虧格），可以拿**外部期望值**核對；
3. 它們恰好是 PSL₂(ℤ) 的算術子群，直接把名詞群的兩項同時兌現。

## 1. 定義

**D-C1（同餘子群）** 令

- Γ(N) = { γ ∈ SL₂(ℤ) : γ ≡ I (mod N) }　（主同餘子群，level N）
- Γ₁(N) = { γ ≡ [[1,\*],[0,1]] (mod N) }
- Γ₀(N) = { γ ≡ [[\*,\*],[0,\*]] (mod N) }

則 Γ(N) ⊆ Γ₁(N) ⊆ Γ₀(N) ⊆ SL₂(ℤ)。**這些包含關係不由手寫規則給出，而是在 SL₂(ℤ/L) 上暴力驗證**。

**D-C2（模 N 的有限群模型）** SL₂(ℤ/N) = { (a,b,c,d) mod N : ad − bc ≡ 1 (mod N) }，乘法為矩陣乘法 mod N。
因 Γ(N) 是歸約映射 SL₂(ℤ) → SL₂(ℤ/N) 的核，γ 屬於哪個同餘子群**只依賴 γ mod N**。

**D-C3（指數）** [SL₂(ℤ) : Γ] 對 Γ ∈ {Γ₀(N), Γ₁(N), Γ(N)} 的封閉公式見 T13。

**D-C4（解析不變量）** 對 X₀(N) = Γ₀(N)∖ℍ\*：
- 尖點數 ν_∞(N) = Σ_{d|N} φ(gcd(d, N/d))；
- 橢圓點數 ν₂(N) = 0（若 4|N），否則 ∏_{p|N}(1 + χ₋₄(p))；
  ν₃(N) = 0（若 9|N），否則 ∏_{p|N}(1 + χ₋₃(p))；
- 虧格 g(N) 由 12g = 12 + ψ(N) − 3ν₂(N) − 4ν₃(N) − 6ν_∞(N) 給出（ψ 為 Dedekind ψ）。

**D-C5（射影模群）** PSL₂(ℤ) = SL₂(ℤ)/{±I}；PSL₂(ℤ/N) = SL₂(ℤ/N)/{±I}。

## 2. 命題

**P-C1（Γ(N) 正規）** Γ(N) ◁ SL₂(ℤ)，因為它是群同態的核。有限群版本：Γ(N) ◁ SL₂(ℤ/N)。**可執行**：對全部元素暴力共軛。

**P-C2（Γ₁(N) 只是 Γ₀(N) 的正規子群）** Γ₁(N) ◁ Γ₀(N) 且 Γ₀(N)/Γ₁(N) ≅ (ℤ/N)^×；
但 N ≥ 2 時 Γ₁(N) **不**在 SL₂(ℤ/N) 中正規（B0003 給出顯式共軛見證）。

**P-C3（−I 的歸屬）** −I ∈ Γ₀(N) **恆真**（其 c = 0）；−I ∈ Γ₁(N) 或 Γ(N) ⟺ N | 2。
＊開發期修正（DOC-4）＊ 首版把三種子群混為一談，檢核器在 N = 3 上立刻紅燈。

**P-C4（PSL₂ 的階）** N ≥ 3 時 |PSL₂(ℤ/N)| = |SL₂(ℤ/N)|/2；N = 2 時 −I ≡ I，故
|PSL₂(ℤ/2)| = |SL₂(ℤ/2)| = |S₃| = 6。＊這條也是開發期被檢核器糾正的（見 §7）。＊

## 3. 定理 T13（指數公式）

對 N ≥ 1：

| 子群 | 指數 [SL₂(ℤ) : Γ] | 公式 |
|---|---|---|
| Γ₀(N) | ψ(N) = N∏_{p\\|N}(1 + 1/p) | `index_gamma0` |
| Γ₁(N) | ψ(N)·φ(N) | `index_gamma1` |
| Γ(N) | ψ(N)·φ(N)·N = N³∏_{p\\|N}(1 − 1/p²) | `index_gamma_level` |

**驗證方式**：對 N = 2..6，在 SL₂(ℤ/N) 上**暴力**數元素（`index_by_bruteforce`），與公式逐項比較。
另外 [Γ₀ : Γ₁] = φ(N)、[Γ₁ : Γ] = N 也以數元素核對（`check_quotient_orders`）。

## 4. 定理 T14（X₀(N) 的解析不變量）

**T14** 對 N ≥ 1，X₀(N) 的尖點數、橢圓點數與虧格由 D-C4 的公式給出，並且：

1. ν_∞(p) = 2（p 質數）、ν_∞(p²) = p + 1；
2. X₀(1) 有 ν₂ = ν₃ = ν_∞ = 1、g = 0（橢圓點 i 與 ρ）；
3. 對 N = 1..24，公式給出的虧格與**古典虧格表**逐一相同（見下表）。

表外的 N 一律回報「未檢核」，不以程式自己的輸出當期望值。
