## 0. 研究對象與動機

工程要求「**全局公理伽羅瓦對應**」。伽羅瓦理論的本質結構不是「多項式的根」，而是：

> 一個二元關係 R ⊆ A × S 誘導出兩側集合冪集之間的一對**反單調伴隨函子**，
> 其複合給出兩側的**閉包算子**，閉集（= 公理閉包 / 陳述閉包）之間存在**反序格同構**。

因此「公理系統」與「演算法陳述系統」不是兩件事，而是同一個形式上下文 (A, S, R) 的兩面。
B0001 把這個結構**完全公理化並演算法化**：從 X0 一條全局公理 + X1–X4 四條局部公理出發，
推出四條定理（T1–T4），再由定理的**構造性內容**得出六個演算法（A1–A6）。
這就是「由公理得出演算法」的完整鏈條：`公理 → 命題 → 引理 → 定理 → 演算法 → 等式 → 可執行檢核`。

## 1. 定義（Definitions）

**D1（形式上下文）** 形式上下文為三件組 K = (A, S, R)，其中
- A 為**公理集**，|A| = m < ∞，元素記 a, a′, …；
- S 為**陳述集**（演算法條目的可判定命題），|S| = n < ∞，元素記 s, s′, …；
- R ⊆ A × S 為**派生關係**；(a, s) ∈ R 讀作「公理 a 支撐（導出）陳述 s」。

記 row(a) = { s ∈ S | (a,s) ∈ R }（a 的**支撐集**），col(s) = { a ∈ A | (a,s) ∈ R }（s 的**見證集**）。
程式對應：`@context.FormalContext`（`rows : Array[@bitset.BitSet]`、`cols : Array[@bitset.BitSet]`）。

**D2（內涵映射 Φ）** Φ : 2^A → 2^S，
　Φ(X) = ⋂_{a∈X} row(a)，並約定 Φ(∅) = S（空族之交為全集，即空真）。
程式對應：`@context.FormalContext::intent`。

**D3（外延映射 Ψ）** Ψ : 2^S → 2^A，
　Ψ(Y) = ⋂_{s∈Y} col(s)，並約定 Ψ(∅) = A。
程式對應：`@context.FormalContext::extent`。

**D4（兩側閉包算子）** cl_A := Ψ ∘ Φ : 2^A → 2^A，cl_S := Φ ∘ Ψ : 2^S → 2^S。
程式對應：`@galois.closure_axioms`、`@galois.closure_stmts`。

**D5（閉集）** X ⊆ A 稱**閉**（X 是**公理閉包**／**公理體系**）若 cl_A(X) = X；
Y ⊆ S 稱**閉**（Y 是**陳述閉包**）若 cl_S(Y) = Y。
程式對應：`@galois.is_closed_axioms`、`@galois.is_closed_stmts`。

**D6（形式概念、概念格）** 對 (X, Y) 稱**形式概念**若 Φ(X) = Y 且 Ψ(Y) = X；
X 稱外延、Y 稱內涵。全體概念以 (X₁,Y₁) ≤ (X₂,Y₂) ⟺ X₁ ⊆ X₂ 排序，記為 B(K)（概念格）。
程式對應：`@lattice.concept_of`、`@lattice.concept_count`。

**D7（蘊含、公理基）** 對 P, Q ⊆ S，蘊含 P → Q 意為：對所有閉集 Y ⊆ S（或等價地所有 cl_A 閉集），P ⊆ Y ⟹ Q ⊆ Y。
一組蘊含 Σ 稱 K 的**完備公理基**若：∀Y ⊆ S，Y 閉 ⟺ Y 對 Σ 中每條蘊含封閉（P ⊆ Y ⟹ Q ⊆ Y）。
Σ 稱**非冗餘**若 Σ 的任何真子集都不是完備基。
程式對應：`@lattice.implies_respects`、`@lattice.check_basis_completeness`、`@lattice.check_basis_nonredundant`。

**D8（偽內涵）** P ⊆ S 稱**偽內涵**若
　(i) P ≠ Φ(Ψ(P))（即 P 不閉），且
　(ii) 對每個偽內涵 Q ⊊ P 有 Φ(Ψ(Q)) ⊆ P。
程式對應：`@lattice.pseudo_intents`。

## 2. 公理（Axioms）

### X0（**全局公理**：伽羅瓦對應）
> 對任何有限上下文 K = (A, S, R)，由 D2、D3 定義的 (Φ, Ψ) 構成**反單調伴隨對**：
> 　　**∀X ⊆ A, ∀Y ⊆ S： X ⊆ Ψ(Y) ⟺ Y ⊆ Φ(X)。**
> 換言之，「公理系統 ↔ 陳述系統」之間的伽羅瓦對應是**全域結構原則**，不依賴任何個別公理內容。

X0 是全域公理：它不宣稱任何具體數學事實，只宣稱派生關係的**伴隨結構必然存在**。
它是本工程「全局公理伽羅瓦對應」的字面實現。
程式對應（可反例搜尋）：`@galois.find_adjunction_counterexample`。

### X1（**局部公理 LA-1：有限性與單調性** ／ Finitary monotonicity）
> 對 X ⊆ X′ ⊆ A 有 Φ(X′) ⊆ Φ(X)；對 Y ⊆ Y′ ⊆ S 有 Ψ(Y′) ⊆ Ψ(Y)。
> 且 A、S 有限，故所有閉集、概念與蘊含皆可有限枚舉。

由 X1 得出**有限性推論**：閉集族 ⊇ 概念族 ⊇ 偽內涵族皆有限，故 A2、A3 的枚舉一定終止。

### X2（**局部公理 LA-2：支撐完全性** ／ Total support）
> 每條公理至少支撐一條陳述：∀a ∈ A，row(a) ≠ ∅；
> 每條陳述至少有一條公理見證：∀s ∈ S，col(s) ≠ ∅。

（X2 排除「空支撐公理」與「不可導出陳述」兩種退化，使 T2 的單射性、T3 的分解性有內容。）

### X3（**局部公理 LA-3：分離性** ／ Separation）
> 任意兩條相異公理可被某條陳述分離：
> 　∀a ≠ a′ ∈ A，∃s ∈ S： (a,s) ∈ R ∧ (a′,s) ∉ R，
> 等價地 **row(a) ⊄ row(a′) 對所有 a′ ≠ a 成立**。

X3 是「無冗餘、無隱含公理」的可判定形式（見 T2）。

### X4（**局部公理 LA-4：局部性** ／ Component locality）
> 考慮 R 的關聯二分圖 Γ(K) = (A ⊎ S, R)。Γ(K) 的每個連通分量 C 決定一對
> (A_C, S_C) 及子上下文 K_C = (A_C, S_C, R|_{A_C×S_C})；
> K 為其分量的**不交併**（direct sum）：A = ⊎_C A_C、S = ⊎_C S_C、R = ⊎_C R_C。
> 派生只沿分量傳播：不存在跨分量的支撐（即 X4 的圖論內容）。

由 X4 得出 T3：公理組合的**局部化**與**跨分支坍縮**。
程式對應：`@context.components_of`、`@galois.local_closure`。

> **局部公理由 B0001 自訂**（依工程內容2 第 2 條）。選取理由：X1 保證可枚舉、X2 排除退化、
> X3 使「重建」有內容、X4 使「組合」有結構（對應組合範例第 7 條「推出／自由積讓共有子結構等同」的離散版）。

## 3. 命題（Propositions）

**P1（反單調性）** 若 X ⊆ X′ 則 Φ(X′) ⊆ Φ(X)；若 Y ⊆ Y′ 則 Ψ(Y′) ⊆ Ψ(Y)。
*證明.* X ⊆ X′ ⟹ {row(a) | a ∈ X} ⊆ {row(a) | a ∈ X′}，較大族之交 ⊆ 較小族之交；Φ(∅)=S 為最大元，端點情形相容。Ψ 同理。∎
程式對應：`@galois.check_antitone`。

**P2（閉包三性）** cl_A 與 cl_S 皆為**擴張、單調、冪等**的閉包算子。
*證明.* 擴張 = C1；單調 = P1 兩次（反單調∘反單調 = 單調）；冪等 = L3。∎
程式對應：`@galois.check_closure_operator`。

**P3（Moore 族）** 兩側閉集族 ℭ_A、ℭ_S 對**任意交**封閉，且分別含 A、S 為最大元；故 (ℭ_A, ⊆)、(ℭ_S, ⊆) 皆為**完備格**，其中 ⊓ = 交，⊔ = 取閉包後之併。
*證明.* 設 {X_i} ⊆ ℭ_A。由擴張 ⋂X_i ⊆ cl_A(⋂X_i)；由單調 cl_A(⋂X_i) ⊆ cl_A(X_i) = X_i（∀i），故 cl_A(⋂X_i) ⊆ ⋂X_i。兩向夾逼得等號，即 ⋂X_i ∈ ℭ_A。最大元 A 顯見閉。有限格 + 任意交封閉 ⟹ 完備格（⊔_i X_i := cl_A(⋃_i X_i)）。∎
程式對應：`@galois.check_moore_family`。

**P4（對偶／反序格同構）** Φ|ℭ_A : ℭ_A → ℭ_S 與 Ψ|ℭ_S : ℭ_S → ℭ_A 互為反序逆映射；即
　　**ℭ_A ≅ (ℭ_S)^op**（反序格同構），且 |ℭ_A| = |ℭ_S| = |B(K)|。
*證明.* 若 X ∈ ℭ_A 則 Φ(X) ∈ ℭ_S，因 ΦΨ(Φ(X)) = Φ(X)（L3）；且 Ψ(Φ(X)) = cl_A(X) = X。反之亦然。反單調由 P1；完備格之間的反序雙射必為反序同構（因雙射保所有交、併）。∎
程式對應：`@galois.check_duality`。

**P5（計數等式）** |ℭ_A| = |ℭ_S| = |B(K)|。（P4 的計數推論，供 A2/A5 交叉檢核。）
程式對應：`@lattice.concept_count`（A 側）與 `@lattice.closed_stmt_count`（S 側）。

**P6（偽內涵列舉正確性，支撐 A3）** 若所有基數嚴格小於 |P| 的子集皆已判定是否為偽內涵，則 P 為偽內涵 ⟺
　(i) P ≠ cl_S(P)，且 (ii) 對所有已判定之偽內涵 Q ⊊ P 有 cl_S(Q) ⊆ P。
*證明.* 條件 (ii) 中涉及的每個 Q 都滿足 Q ⊊ P，故 |Q| < |P|，已判定；將「已判定」代入 D8 的定義即得等價。∎
（此命題把 D8 的非良基形式轉為**按基數遞增**的可執行演算法，複雜度見 E9。）

**P7（與擬陣／閉包系統的關係）** 若在 P2 上追加**交換公理**（X ⊆ Y, y ∈ cl(Y) ⟹ cl(X ∪ {y}) ∋ y′ ∈ Y∖X 者），則 ℭ_A 為擬陣閉集族；本框架是擬陣、Moore 族、Horn 蘊含系統、FCA 概念格四者的**共同下界**。
（此命題為註記性，B0001 不實作交換公理；登記為 B0002+ 的擴展。）

## 4. 引理（Lemmas）

**L1（伴隨律 / 量化互換）** ∀X ⊆ A, Y ⊆ S： X ⊆ Ψ(Y) ⟺ Y ⊆ Φ(X)。
*證明.* X ⊆ Ψ(Y)
⟺ ∀a∈X: a ∈ ⋂_{s∈Y} col(s)
⟺ ∀a∈X ∀s∈Y: (a,s) ∈ R
⟺ ∀s∈Y ∀a∈X: (a,s) ∈ R
⟺ ∀s∈Y: s ∈ ⋂_{a∈X} row(a)
⟺ Y ⊆ Φ(X)。∎（僅用量詞互換，因此對無窮上下文亦成立。）
程式對應：`@galois.check_adjunction`（窮舉或抽樣反例搜尋）。

**L2（複合單調性）** Φ∘Ψ 與 Ψ∘Φ 皆單調（P1 ×2）。

**L3（三角恆等）** ΦΨΦ = Φ 且 ΨΦΨ = Ψ。
*證明.* 以 X 代 L1 之 (X, Φ(X)) 得 X ⊆ ΨΦ(X)（因 Φ(X) ⊆ Φ(X)），於是由 P1：
Φ(ΨΦ(X)) ⊆ Φ(X)。另一方面以 Φ(X) 代 L1 之 X 得 Φ(X) ⊆ ΦΨΦ(X)。兩向夾逼得 ΦΨΦ = Φ。ΨΦΨ = Ψ 同法。∎

**C1（擴張性推論）** X ⊆ cl_A(X)，Y ⊆ cl_S(Y)。（L3 證明的第一式。）

**L4（穩定化：單次雙閉包即定點）** cl_A(cl_A(X)) = cl_A(X)。
*證明.* ΨΦΨΦ = Ψ(ΦΨΦ) = ΨΦ（L3）。∎
**演算法意涵（關鍵）**：閉包計算**不需要迭代到定點**，一次 Φ 再一次 Ψ 即得；這使 A1 為 O((|X|·n + |Φ(X)|·m)/64) 而非迭代型。

## 5. 定理（Theorems）

### T1（**全局公理伽羅瓦對應定理**，GAGC）
對任何滿足 X0、X1 的有限上下文 K：
1. (Φ, Ψ) 是反單調伴隨對（L1）；
2. cl_A = Ψ∘Φ、cl_S = Φ∘Ψ 為閉包算子，且**單次即定點**（P2, L4）；
3. ℭ_A、ℭ_S 為 Moore 族，各為完備格（P3）；
4. Φ|ℭ_A 與 Ψ|ℭ_S 互為反序逆映射，ℭ_A ≅ (ℭ_S)^op，|ℭ_A| = |ℭ_S| = |B(K)|（P4, P5）。
*推論（演算法方向）*：枚舉只需在一側（例如 S 側）進行，另一側由 Ψ 傳遞；
閉集判定只需一次雙閉包；格的覆蓋關係可由「加入一個元素再閉包取極小者」求得（上覆蓋，A5）。
　　　　　　＊警告：其對偶寫法「去掉一個元素再閉包取極大者」是**錯的**，反例見 §6 A5 註記與 E13。＊

### T2（**重建定理**：X3 ⟺ 公理為閉單點）
在 X1 下，下列三條等價：
　(a) X3 成立（分離性）；
　(b) 對所有 a ∈ A，cl_A({a}) = {a}（每條公理都是**閉單點**，無公理可被其餘公理導出）；
　(c) 映射 a ↦ row(a) 為單射，且對所有 a′ ≠ a 有 row(a) ⊄ row(a′)。
*證明.* cl_A({a}) = Ψ(Φ({a})) = { a′ ∈ A | row(a) ⊆ row(a′) }。
故 cl_A({a}) = {a} ⟺ 不存在 a′ ≠ a 使 row(a) ⊆ row(a′)，此即 (c) 之後半；而 (c) 之「單射」由「互不包含」立得（若 row(a) = row(a′) 則互相包含，矛盾）。X3 的等價式即 (c) 之後半。∎
*意義*：T2 給出「公理系統是否冗餘」的**可執行判準**：跑 A6 一次即知；若某 a 的 cl 非單點，則 a 可由其他公理導出，應併入 A3 的蘊含基並刪除。程式對應：`@galois.redundant_axioms`。

### T3（**局部性定理**：分量分解與跨分支坍縮）
在 X2 下，設 Γ(K) 的連通分量為 {C_i}_i，A_i = A ∩ C_i、S_i = S ∩ C_i。
1. 若 X ⊆ A 觸及**至少兩個**分量（即存在 a, a′ ∈ X 落在不同分量），則 Φ(X) = ∅，從而 cl_A(X) = A（**跨分支坍縮**：不共享任何陳述的公理一旦並置，閉包退化為全域）。
2. 若 X ⊆ A_i ≠ ∅ 且 Φ(X) ≠ ∅，則 cl_A(X) = cl_{A_i}(X) ⊆ A_i（**局部封閉**：閉包不越出分量）。
3. 若 X ⊆ A_i 且 Φ(X) = ∅，則 cl_A(X) = A。
4. 故：任何**真**閉集（≠ A）必整個落在單一分量內，且為該分量上下文之閉集；A 本身自成一閉集。
*證明.* (1) 不同分量的 row 分別落在互不相交的 S_i、S_j，且由 X2 皆非空；非空不交集合之交為空 ⟹ Φ(X)=∅ ⟹ Ψ(∅)=A（D3 約定）。
(2) X ⊆ A_i ⟹ Φ(X) ⊆ S_i；Ψ(Φ(X)) = {a | row(a) ⊇ Φ(X)}。若 a ∈ A_j（j ≠ i），由 X2 的 row(a) ⊆ S_j 且 Φ(X) ⊆ S_i、Φ(X) ≠ ∅，故 row(a) ⊉ Φ(X)，即 a ∉ cl_A(X)。故 cl_A(X) ⊆ A_i，且判定條件與 A_i 內完全相同，故與 cl_{A_i}(X) 一致。
(3) Φ(X)=∅ ⟹ Ψ(∅)=A。
(4) 由 (1)(2)(3) 直接分類。∎
*演算法意涵*：A4 以並查集切分量，把全域閉包計算降為分量內計算；
並可在 A2 的 lectic 走訪中**提前剪枝**：一旦候選集合跨越兩分量，其閉包必為 A，無須計算交集鏈。

### T4（**Duquenne–Guigues 典範基定理**）
在 X0、X1 下，Σ := { P → cl_S(P) | P 為偽內涵（D8）} 是 K 的**完備且非冗餘**的蘊含基。
*要點（標準證明，Duquenne–Guigues 1986；此處僅錄結構）*
- **健全**：每條 P → cl_S(P) 對所有閉集成立（若閉集 Y ⊇ P，由 P ⊆ Y 及 Y 閉得 cl_S(P) ⊆ cl_S(Y) = Y）。
- **完備**：設 Y 對 Σ 封閉而 Y ≠ cl_S(Y)。取 Y ⊆ P 的**基數極小**偽內涵 P（存在性由 Y 非閉推得，標準論證：Y 本身若不閉，經閉包運算迭代產生鏈，鏈首即為候選偽內涵）。則 cl_S(P) ⊄ Y 與 P ⊆ Y 矛盾於「Y 對 Σ 封閉」。
- **非冗餘**：每條 P → cl_S(P) 的右端含 cl_S(P)∖P 中元素，而該元素不被其餘蘊含導出（偽內涵的極小性），故刪去任一條即失去完備性。
＊B0001 以可執行方式檢核「完備」（`@lattice.check_basis_completeness`，窮舉所有子集）與「非冗餘」（`check_basis_nonredundant`：逐條刪除後重檢完備性）。＊

| A1 | `galois_biclosure` | T1(2)、L4 | (K, X⊆A 或 Y⊆S) → cl | O((|X|·⌈n/64⌉ + |Φ(X)|·⌈m/64⌉)) | O(m+n) 位元 |
| A2 | `next_closure` | T1(1)(3)、P2 | K → 全部閉集（lectic 序，多項式延遲） | 延遲 O(n·(⌈m/64⌉+⌈n/64⌉)+cl)；總量 O(|ℭ|·n·…) | O(|ℭ|·n) |
| A3 | `canonical_basis` | P6、T4 | K → 偽內涵及其閉包（DG 基） | O(2^n · n · |Σ|) 最壞（輸出指數本質） | O(|Σ|·n) |
| A4 | `components` + `local_closure` | X4、T3 | K → 分量 {A_i,S_i}；(K,X) → cl 且標記坍縮 | DSU O((m+n+|R|)·α)；局部閉包 O(\|X\|·⌈n_i/64⌉+…) | O(m+n) |
| A5 | `concept_lattice` + `upper_covers` | T1(4)、P4 | K → 概念數、Hasse 覆蓋邊（上覆蓋） | O(|ℭ|·n·cl + |ℭ|·n²) | O(|ℭ|·n) |
| A6 | `verify_*`（反例搜尋器） | X0、L1、P2–P4、T2、T3、T4 | K → 檢核報告（含反例） | 窮舉上限內 2^m·2^n | O(m+n) |

**設計要點**
1. **位元平行**：Φ/Ψ 以 UInt64 交集鏈實作（`@bitset`），複雜度帶 ⌈n/64⌉ 因子而非 n。
2. **單次定點**（L4）：不做迭代，避免 O(迭代) 因子。
3. **多項式延遲**（A2）：NextClosure 每次只需 O(n) 次「加一元素再閉包」。
4. **分量剪枝**（T3）：跨分量候選直接判為 A，省去交集鏈。
5. **可檢核性**：每個定理都有對應的判準函式（A6），在登記的樣本上下文上給出 PASS/FAIL 與反例。

**A5 的公式選擇（實測教訓）**：上覆蓋
　　covers(Y) = min{ cl_S(Y ∪ {s}) | s ∉ Y }
是正確的：任一極小真閉超集 Z ⊋ Y，取 s ∈ Z∖Y 即得 cl_S(Y∪{s}) ⊆ Z 且 ⊋ Y，故等於 Z。
相反的「下覆蓋 = max{ cl_S(Y∖{s}) | s ∈ Y }」**錯**：
在 `divisibility` 樣本中 Y = {6,12,18} 的真閉子集 {12} 滿足 cl_S(Y∖{s}) = Y（∀s ∈ Y），永遠取不到。
此反例由 A6 檢核 `check_covers` 抓到並保留為常設檢核；等式見 E13。

## 7. 等式（Equalities，供 algorithm.xlsx 交叉索引）

- **E1** Φ(X) = ⋂_{a∈X} row(a)，Φ(∅) = S
- **E2** Ψ(Y) = ⋂_{s∈Y} col(s)，Ψ(∅) = A
- **E3** cl_A = Ψ∘Φ，cl_S = Φ∘Ψ
- **E4** X ⊆ Ψ(Y) ⟺ Y ⊆ Φ(X)　　　（伴隨律，X0／L1）
- **E5** ΦΨΦ = Φ，　ΨΦΨ = Ψ　　　（三角恆等，L3）
- **E6** cl_A∘cl_A = cl_A，　cl_S∘cl_S = cl_S　（冪等，L4）
- **E7** ℭ_A ≅ (ℭ_S)^op，　|ℭ_A| = |ℭ_S| = |B(K)|　（反序格同構，P4/P5）
- **E8** cl_A({a}) = { a′ | row(a) ⊆ row(a′) }　（單點閉包，T2）
- **E9** 偽內涵判定：P ∈ PI ⟺ P ≠ cl_S(P) ∧ ∀Q ∈ PI, Q ⊊ P ⟹ cl_S(Q) ⊆ P　（D8／P6）
- **E10** cl_A(X) = A ⟺ Φ(X) = ∅　（X2 下，T3(1)(3)）
- **E11** Γ(K) 分量 C_i：A = ⊎A_i，S = ⊎S_i，R = ⊎R_i　（X4）
- **E12** Σ = { P → cl_S(P) | P ∈ PI } 完備且非冗餘（T4）
- **E13** covers(Y) = min{ cl_S(Y ∪ {s}) | s ∉ Y }　（上覆蓋；對偶的 cl_S(Y∖{s}) 取極大者不成立）
