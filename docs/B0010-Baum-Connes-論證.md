## §0 論證的形狀（先說清楚「能證明什麼、不能證明什麼」）

古典 Baum–Connes 猜想（無係數版）說：對可數離散群 G，組裝映射

  μ_i^G : K_i^G(EG) → K_i(C*_r G),   i = 0, 1

是同構，其中 EG 是真作用的分類空間。截至 **2026 年 9 月**，這條猜想**沒有已知反例**
（arXiv:2610.01802《The Baum-Connes conjecture: a concise course》明言 as of September 2026
no counter-example is known），對一般 second-countable locally compact 群仍**開放**。

本輪**不可能**證明它（任何有限計算都不能）。本輪做的是三件**可執行**的事：

1. **把猜想在「兩側都能完整算出」的樣本上判定為真**——不是引用文獻，而是把兩側算式寫出來對撞：
   左側 R(G) 與右側 K₀(ℂG) 的自由秩、跡泛函、特徵正交性、Wedderburn 分解，全部用 ℚ 上的精確消去法算。
2. **給出判準的負控制**，使每條「綠燈」都不是恆真：正交性抽掉類大小權重就失敗、
   DFT 把 ζ 當成 1 就崩潰、A₄ 若只用 ℚ 就少一個不可約表示、伽羅華對應若只用維度就分不清三個二階子群。
3. **把界外逐條登記**（BC1–BC8），每條附文獻現況、本引擎**真的算得出**的那一塊、
   以及**兩個可能值**——「不決定」因此是可檢核的斷言（沿用 B0006 的 A-K5）。

> 界外不得以綠燈冒充。本文件 §5 的 BC1–BC8 全部 `decides = false`，T88／T90 會驗這件事。

## §1 樣本：兩側都可算的群

**D-BC1**：有限群 G 的資料 `FinGroup{name, order, class_sizes, table}`；
`table[V][C] = χ_V(C)`（列 = 不可約表示，行 = 共軛類，第 0 行是單位元類）。

**D-BC2**：對有限群，BC 猜想退化為

  EG = 點（真作用的分類空間對有限群是點），
  K₀^G(pt) = R(G)（表示環，自由交換群，秩 = #不可約表示），
  C*_r G = ℂG ≅ ⊕_V M_{dim V}(ℂ)（Wedderburn），
  故 K₀(ℂG) = ℤ^{#irr}、K₁(ℂG) = 0（GL_d(ℂ) 連通 ⇒ 拓撲 K₁ = 0）。

於是 μ₀ : R(G) → K₀(ℂG) 是 ℤ^{#irr} → ℤ^{#irr}，而它與跡泛函 τ_g（取 g 的係數）的複合
**就是特徵表**：μ₀ 的座標 = χ_V(C)。這是全部計算的支點，也是「代數 K-群」與「表示環」之間
唯一需要驗證的等式。

**D-BC3**：判準 `bc_assembly_iso(G)`：
（1）#irr = #cc；（2）特徵表滿秩（ℚ 高斯）；(3) F_p 高斯秩相同（`@cyclic.rank_q`）；
（4）Σ_V (dim V)² = |G|；（5）類大小總和 = |G|；（6）帶權重 Gram = |G|·I。

**T81（有限群 Baum–Connes）**：對 ℤ/2、V₄、S₃、D₈、Q₈，μ₀ 是群同構。實算值：

| G | \|G\| | #irr = #cc | rank(ℚ/F_p) | Σ dim² |
|---|---|---|---|---|
| ℤ/2 | 2 | 2 | 2 / 2 | 2 |
| V₄ = ℤ/2×ℤ/2 | 4 | 4 | 4 / 4 | 4 |
| S₃ | 6 | 3 | 3 / 3 | 1+1+4 = 6 |
| D₈ | 8 | 5 | 5 / 5 | 4·1+4 = 8 |
| Q₈ | 8 | 5 | 5 / 5 | 4·1+4 = 8 |

**T82（正交性與其負控制）**：帶類大小權重的正交性 Σ_C |C|χ_V(C)χ_W(C) = |G|δ_VW 對五個樣本成立；
負控制：把每個共軛類都當成大小 1，S₃ 的 ⟨triv,triv⟩ = 3 ≠ 6、D₈ = 4 ≠ 8 ⇒ 判準立刻失敗。
**這就是「μ 單射」為什麼不是恆真**：單射性等價於特徵表滿秩，而滿秩的理由是正交性，
正交性的權重來自共軛類的實際大小。

## §2 循環群：μ 矩陣 = 離散傅立葉矩陣（T83）

**D-BC4**：ℤ/n 的特徵表是 F = (ζ^{jk})_{j,k}（j = 不可約表示、k = 共軛類 = 元素），即 DFT。

**T83**：F 可逆 ⟺ μ 同構，而 F 可逆的實質理由是**單位根的和**

  Σ_{k=0}^{n−1} ζ^{km} = n·δ_{m,0},

在 ℚ(ζ_n) 的整數基底座標裡**精算**（`cyclo_dft_sum`，靠 B0009 的 Φ_n 降次），n = 2..12 全通。
負控制：把 ζ 當成 1（退化到么代數）時，同一個和對所有 m 都等於 n ⇒ 正交性崩潰（`check_dft_collapse_fails`）。

**這一條把 B0009 的兩個名詞接進 BC**：「圓體擴張伽羅華群」供給 R(ℤ/n) 的分圓基底，
「圓周群的所有單位根群」供給分母 μ_n 的加法結構；F 可逆正是兩者在 ℚ/ℤ 上的配對非退化。

## §3 非整數特徵表：A₄ 與 ℤ[ω]（T84）

**D-BC5**：A₄ 的特徵表落在 ℤ[ω]（ω = e^{2πi/3}）：
χ₁ = (1,1,1,1)、χ_ω = (1,1,ω,ω²)、χ_{ω²} = (1,1,ω²,ω)、χ₃ = (3,−1,0,0)，
共軛類大小 (1,3,4,4)。

**演算法**：把 ℤ[ω] 當 2 維 ℚ-向量空間，元素 a + bω ↦ 2×2 區塊 [[a, −b], [b, a − b]]（ω² = −1 − ω），
於是 r×r 的 ℤ[ω]-矩陣展開成 2r×2r 的整數矩陣；「ℂ 上滿秩」⟺「展開後秩 = 2r」。
這樣就能用同一套 ℚ 高斯（`@analytic.rmat_rank`）與 F_p 高斯（`@cyclic.rank_q`）。

**T84**：展開秩 = 8 = 2·4（兩套演算法一致）、帶權重 Gram = 12·I ⇒ μ₀ : R(A₄) → K₀(ℂA₄) 是同構。
**負控制**：若**只用 ℚ**（χ_ω 與 χ_{ω²} 在 Gal 下共軛，有理特徵理論只能看到它們的和 (2,2,−1,−1)），
秩掉到 6 < 8 ⇒ 少數一個不可約表示。**ℤ[ω] 不可省**。

## §4 與前幾輪的接縫（T85、T86、T87）

**T85（S_n 與 SL₂(𝔽₂)）**：
(a) 對 S_n（n ≤ 5）：暴力算出的共軛類個數 = 分割數 p(n) = B0006 的 `k_of_symmetric_group` 給的
K₀(C*(S_n)) 秩，且 Σ_λ d_λ² = n!（Wedderburn ⇒ K₁ = 0）。兩側同秩 ⇒ μ 同構。
S₃：3/3；S₄：5/5；S₅：7/7。
(b) SL₂(𝔽₂) ≅ S₃：B0003 的 `sl2_group(2)` 暴力共軛類 = 3 = T81 的 S₃ 行 ⇒ 同一個群兩條路徑給同一個 K₀ 秩。

**T86（Kadison–Kaplansky 的代數截面）**：BC 滿射 + **無撓** ⇒ 群代數無非平凡冪等元。
* ℂ[ℤ] = ℂ[t, t⁻¹]：**次數論證**封閉所有情形——deg p = k ≥ 1 ⇒ deg(p²) = 2k > k ⇒ p² ≠ p
  （首項係數 a_k² ≠ 0，ℂ 是整域）；另有**窮舉截面**：支撐 [−2,2]、係數 {−1,0,1} 的 243 個多項式逐個檢查。
* 負控制：ℂ[ℤ/2] 的 e = (1+g)/2 確實冪等（ℚ 精算）⇒「有撓 ⇒ 有非平凡冪等元」，
  **無撓假設不可省**。

**T87（G = ℤ，接 B0006）**：ℤ 無撓且 a-T-menable（Higson–Kasparov 已證），C*_r ℤ = C(S¹)。
組裝兩側：K_i^ℤ(Eℤ) = K_i(C(S¹)) = (ℤ, ℤ)，μ = id。
用 B0006 的 Toeplitz 六項正合列（`check_six_term_toeplitz`：六個節點的 g∘f = 0 與秩—零化度判準）
與指標／繞數檢核（∂₁ = ×1，`check_index_winding`）**獨立**核對 C(S¹) 的 K-群是 (ℤ, ℤ)。

## §6 需求文件另兩行的落地（T89、T90）

工程內容2 的第 1、2 行是「**全局公理伽羅華對應**」與「**局部公理由你決定**」。
這兩行在 **B0001** 已是主體（X0 全局公理 + T1 GAGC；X1–X4 四條局部公理由本工程自訂）。
R11 把它們在 Baum–Connes 的情境中**再落地一次**，且這次是數論層與紀錄層各一：

**T89（全局公理伽羅華對應，數論層）**：對 G = (ℤ/n)^× 的**全體子群**，

  H ⊆ H′ ⟺ ℚ(ζ_n)^H ⊇ ℚ(ζ_n)^H′，且 H ↦ ℚ(ζ_n)^H 是單射（反序一一對應到中間體），
  dim ℚ(ζ_n)^H = [G : H]。

n ∈ {5,7,8,9,12} 的全部子群對逐對核對。子空間包含以**堆疊後的秩**判定
（rank(rows_H ∪ rows_H′) = rank(rows_H) ⟺ Fix(H) ⊆ Fix(H′)）。
**負控制（本例自帶）**：只用維度比較時，V₄ = (ℤ/8)^× 的三個二階子群維度都是 2，
維度相等分不清三個不同的不動子空間 ⇒ 判準必須做子空間比較。`check_dimension_only_fails()` 驗這條。

形式層（B0001 的 (·)′ 伽羅瓦連接）與數論層的接口：Fix(H) 的計算就是「把 H 的每個 σ_k 寫成
(σ_k − I) 的行、取核」——線性化了的「屬性被物件共同滿足」。兩層同構，故「全局公理伽羅華對應」
在本輪有**兩個獨立見證**（B0001 的概念格引擎、B0010 的不動子空間引擎）。

**T90（局部公理由代理決定）**：把「誰決定了什麼」寫成資料結構 `AxiomRecord{id, statement,
global, procedure, verdict, witness}`：

* **局部公理 8 條**（每個可算樣本一條「μ 對該 G 是同構」）：`global = false`、`verdict = true`、

## §7 論證的結論（逐句可對照檢核）

1. **樣本上成立**：對 8 個可算樣本，組裝映射是同構，且這是**兩側算式對撞**的結果
   （#irr = #cc、特徵表滿秩、Σ dim² = |G|、正交性、DFT 正交、ℤ[ω] 展開秩），不是引用（T81、T83、T84、T85、T87）。
2. **判準有內容**：每一類都有一條合法的退化使判準失敗（T82、T83、T84、T86、T89）。
3. **不越界**：對古典猜想本身，本輪**不宣稱**任何判定；BC1–BC8 全部 `decides = false`
   並列出兩個可能值（T88、T90）。特別是：
   * 有係數版已被 HLS02 否證，**不可**由本輪樣本反推其成立；
   * SL_n(ℤ), n ≥ 3 的滿射性仍開放，本輪的 SL₂(𝔽₂) 只是有限商；
   * 粗版（arXiv:2504.21811）與群版是**不同命題**，不可互相推出。
4. **可重跑**：`moon run cmd/main -- bc`（10/10）、`-- bctable`（兩側並列表＋界外清單）。

## §8 成本與邊界

| 項目 | 上限 | 理由 |
|---|---|---|
| 有限群樣本 | \|G\| ≤ 8、#cc ≤ 5 | 特徵表為整數、秩計算 O(n³) |
| 循環群 | n ≤ 12 | DFT 正交性是 O(n²·φ(n)) 的分圓加法和 |
| A₄ | 展開 8×8 | ℤ[ω] 的 2 倍展開 |
| S_n 接縫 | n ≤ 5 | 共軛類暴力是 O(\|G\|²·n)，n = 5 時 120² |
| 伽羅華對應 | n ∈ {5,7,8,9,12} 的全體子群 | 子群對 ² 次堆疊秩計算 |

**界外**（不得以綠燈冒充）：無窮群的 C*_r G 之 K-群、有係數的組裝映射、
粗組裝、L-理論與高階簽名、SL_n(ℤ) 的滿射性、以及任何「一般群」的普遍陳述。
