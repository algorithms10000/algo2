## §1 analytic 套件：有理精確算術（`rat.mbt`）

**D-A1**：`Rat{num, den}` 為最簡分數（den > 0，符號在 num），`RMat{rows, cols, e}` 為列主序矩陣。

演算法：`rmat_rank`（ℚ 上的高斯消去）、`rmat_det`（帶符號的消去）、`rmat_inv`、
`rmat_norm2`（Frobenius 範數平方 = tr(AAᵀ)）、`rmat_conj`（A ↦ UAU* 的實版本）、
`rmat_mul/add/sub/scale/transpose/trace`、`rmat_of_int`、`rmat_to_int`。

**為什麼一律在 ℚ 上**：本輪所有判準都是「秩／跡／det 是否等於某個有理數」。
浮點會把「288/625 是不是 0」變成ε-判斷；有理算術把它變成整數比較（T72 就是這條的交叉驗證）。

## §2 近似單位元（T64–T65）

**D-A2**：A 為么 C*-代數，網 {e_λ} 是**近似單位元**若
（A1）0 ≤ e_λ ≤ 1；（A2）e_λ 遞增；（A3）‖e_λ a − a‖ → 0；（A4）‖a e_λ − a‖ → 0 對所有 a ∈ A；
（A5，么代數的額外要求）e_λ → 1 在**嚴格拓撲**下。

**樣本**：A = M_N(ℂ)、N = 5，e_n = diag(1,…,1,0,…,0)（前 n 個 1），S = 移位矩陣，P₂ = diag(1,1,0,0,0)。

* **T64（近似單位元）**：對 n = 0..4 精算得
  `‖e_nS − S‖₂² = N − 1 − n = 4,3,2,1,0`；
  `‖(1−e_n)P₂‖₂² = 2,1,0,0,0`；
  遞增性 e_n ≤ e_{n+1} 逐項成立（`check_approx_conv_projection`）。
* **T65（負控制：么代數上同一序列不是近似單位元）**：
  在**么**代數 M_N(ℂ) 上，`approx_negative_unital` 精算得
  `‖e_n·1 − 1‖₂² = N − n = 5, 4, 3, 2, 1`（n = 0..4），**全部 > 0**：
  么代數的近似單位元只能是 1 本身，任何真投影 e ≠ 1 都差一截。
  同一序列在**非么**理想 K(H) 上卻是近似單位元——對每個**固定**的有限支撐 a，
  n 足夠大時 e_n a = a（A5 的壓縮計算給出同一件事）。
  負控制的意義很具體：BC 的算子側談的是 C*_r G 的**理想／穩定化**，
  若把「么代數」與「其理想」混為一談，判準會把「{e_n} 不是近似單位元」錯判成「是」。

**與 Baum–Connes 的接口**：BC 的算子側是 C*_r G 的 K-群；近似單位元是
「C*_r G 的穩定有限性／無么穩定性」那一路證法的入口（見 B0010 §2）。

## §3 投影與非交換投影（T66–T68）

**D-A3**：p ∈ A 是投影若 p = p* = p²。
**D-A4**：p, q 正交若 pq = qp = 0；投影和 p+q 是投影 ⟺ p ⊥ q（`check_product_projection_criterion`）。
**D-A5**：Murray–von Neumann 等價 p ~ q ⟺ 存在部分等距 v 使 p = vv*、q = v*v。
**D-A6**：主角度 θ 由 cos²θ 的最大奇異值刻劃；對秩一投影，cos²θ = tr(pq)。

**樣本**：p = E₁₁ = [[1,0],[0,0]]，q = [[9/25,12/25],[12/25,16/25]]（3-4-5 畢氏三元組給的秩一投影，cos θ = 3/5）。

* **T66（投影與 K₀）**：p、q 各自冪等且自伴、跡 = 秩 = 1；`diag_proj(2,5)` 與 p 正交和跡 3；
  K₀ 的加性 [p] + [q] = [p ⊕ q] 由 `block_diag` 逐項核對。
* **T67（Murray–von Neumann）**：p ~ q（同為秩一）給出顯式部分等距；而 {E₁₁, E₂₂} 生成的代數維度
  為 2（= ℂ²），{E₁₁, q} 生成維度 4（= M₂(ℂ)）——`span_dim_rmat` 精算，兩者可區分。
* **T68（非交換投影）**：`pq ≠ qp`、pq **不是**投影、tr(pq) = 9/25、
  `‖pq − qp‖₂² = 288/625`（非零 ⇒ 非交換），並以 cos²θ = 9/25 對撞主角度。
  這是「非交換」判準的定量版本：交換 ⇒ 交換子範數 0；本樣本給出精確的正值。

## §4 自由同倫不變性（T69–T71）

**D-A7**：冪等元路徑 e(t) = (1 + tA)·e·(1 − tA)，其中 **A² = 0**；此時
e(t)² = e(t) 對所有 t 成立，且 e(0) = e。
**D-A8**：自由同倫關係 p ≈ q ⟺ 存在冪等元路徑連接（等價於存在 v, w 使 p = vw、q = wv）。
**D-A9**：K₀ 的秩不變量 rank: K₀(A) → ℤ（么代數上 tr(p)）；K₁ 的行列式不變量。

* **T69（冪等元同倫）**：e = [[1,1],[0,0]]、A = [[0,1],[0,0]]（A² = 0）。族
  t = 0, 1, 2 給出 `[1 1; 0 0] → [1 1/2; 0 0] → [1 0; 0 0]`，
  每個都是冪等元、秩恆為 1。
  **關鍵陷阱（BUG-27）**：用 `antisym_12`（A² = −1）代入同一公式會得到**非**冪等元；
  T71 把這一條做成負控制。
* **T70（自由同倫不變性）**：上述族的所有成員秩都是 1 ⇒ 在 K₀ 中同類；
  Cayley 正交族（以 A² = −1 的生成元造）給出 det 恆 1 的一族么正元，
  而 diag(−1,1) 的 det = −1 ⇒ K₁ 有**兩個分量**，同倫不變性在此處是可分辨的而非恆真。
* **T71（負控制）**：A² = 0 不可省（用 antisym 代入 ⇒ 冪等性失效，回傳 false）；
  不同秩不同類（rank 1 與 rank 2 的路徑不可能同倫）。

**與 Baum–Connes 的接口**：「自由同倫不變性」正是 K-群的同倫不變性；
BC 的左側是**同倫論的**對象（K-同調），右側是**代數的**對象（K-群），
兩者能對撞的前提就是本節的 H1–H4。

## §5 分圓算術：Φ_n 與 ℚ(ζ_n)（T76、T77）

**D-C1**：Φ_n ∈ ℤ[x] 由 x^n − 1 = ∏_{d|n} Φ_d 遞迴定義；`poly.mbt` 以整係數多項式的精確除法實作。
**D-C2**：ℚ(ζ_n) 以基底 1, ζ, …, ζ^{φ(n)−1} 表示；乘法 = 多項式乘法後對 Φ_n 取模。

**T76（分圓多項式）**：對 n ≤ 20：deg Φ_n = φ(n)、Φ_n | x^n − 1，且已知係數逐條對撞：
Φ₁ = x − 1、Φ₅ = x⁴+x³+x²+x+1、Φ₈ = x⁴+1、Φ₁₂ = x⁴−x²+1。

**T77（伽羅華群）**：σ_k : ζ ↦ ζ^k（k ∈ (ℤ/n)^×）是么正環同態、σ_kσ_l = σ_{kl}、
k ↦ σ_k 是雙射 ⇒ **Gal(ℚ(ζ_n)/ℚ) ≅ (ℤ/n)^×**，對 n ∈ {3,4,5,7,8,9,10,12} 逐項核對。
交叉驗證：σ_k 的矩陣用 `@analytic` 的 ℚ-高斯算得 det = ±1（自同構 ⇒ 可逆 ⇒ det 為整數單位）、
F_p 上的秩滿（`@cyclic.rank_q`）。兩套秩演算法必須一致。

## §6 圓周群的所有單位根群（T73–T75）

**T73（μ_n ≅ ℤ/n）**：階為 d 的元素恰有 φ(d) 個（d | n），故 μ_n 循環、生成元 φ(n) 個（n ≤ 16 全通）。
例：n = 12 時 φ(12) = 4，階分佈 [階1→1、階2→1、階3→2、階4→2、階6→2、階12→4]，總和 12。

**T74（ℚ/ℤ ≅ ∪_n μ_n，Prüfer 群）**：元素以最簡分數 a/b 表示，階 = b/gcd(a,b)；
全撓（每個元素的階整除它所屬的 n）、**可除**（對任意 x 與 m ≤ 6，方程 m·y = x 有解，
以分數加法 mod 1 精算），且「階整除 n 的元素」恰為 μ_n（n 個）。

**T75（Pontryagin 對偶）**：μ_n^ ≅ ℤ/n，特徵 χ_j(ζ^k) = ζ^{jk}：
同態性（χ_j(ab) = χ_j(a)χ_j(b)）與非退化性（j ≠ j′ ⇒ 存在 k 使值不同）逐項核對，n = 2..12。

**接口**：ℚ/ℤ 是 BC 左側「圓周群的撓子群」那條線的起點；它同時是 Fourier／DFT 的宿主
（B0010 的 T83 就是 ℤ/n 的組裝映射 = DFT，其可逆性正是 T73–T75 的直接推論）。

## §7 跡、伽羅華對應、二次子體（T78–T80）

**T78（跡 = Ramanujan 和）**：Tr_{ℚ(ζ_n)/ℚ}(ζ^j) = c_n(j) = μ(n/d)·φ(n)/φ(n/d)，d = gcd(n,j)。
精算方式：跡 = Σ_{k∈(ℤ/n)^×} σ_k(ζ^j)，逐座標整數相加，且**高次座標必須全為 0**
（跡是有理數；代數整數 + 有理數 ⇒ 整數）。n ≤ 20 全通。
例：c₅(1) = −1、c₅(0) = 4、c₆(1) = 1、c₈(1) = 0。

**T79（伽羅華對應）**：H ≤ G = (ℤ/n)^× ⇒ dim_ℚ ℚ(ζ_n)^H = [G : H]，
n ∈ {5,7,8,9,12} 的全部循環子群；兩端夾住：H = G 給維度 1（固定體 = ℚ）、H = {1} 給維度 φ(n)。
不動子空間的維度同時用 `@cyclic.rank_q`（F_p）與 `@analytic.rmat_rank`（ℚ）算，必須一致。
**負控制**：k ∉ (ℤ/n)^× 時 ζ ↦ ζ^k 不是自同構——不雙射（存在 a ≠ b 使 ζ^{ak} = ζ^{bk}）
**且**代換不良定義（Φ_n(ζ^k) ≠ 0，在 ℚ(ζ_n) 中精算）。n = 6、k = 2 命中。

**T80（二次子體與分圓特徵）**：
(a) 高斯週期 η = Σ_{k∈QR} ζ_p^k 滿足 η² + η + (1 − (−1)^{(p−1)/2}p)/4 = 0，
即 ℚ(ζ_p) 的唯一二次子體是 ℚ(√((−1)^{(p−1)/2}p))（p = 5,7,11,13 全通）：
p ≡ 1 (mod 4) 給實二次體 ℚ(√p)，p ≡ 3 (mod 4) 給虛二次體 ℚ(√−p)。
(b) 分圓特徵：Gal(ℚ(ζ_n)/ℚ) ≅ (ℤ/n)^× ≅ **Aut(μ_n)**，兩邊的群結構與元素階逐項對撞（n = 3..12）。

這是「圓體擴張伽羅華群」與「圓周群的所有單位根群」兩個名詞**接在一起**的地方：
伽羅華群就是 μ_n 的自同構群，中間的橋是分圓特徵。

## §8 全域檢查（T72 與跨套件交叉）

* **T72（秩的兩套演算法）**：`rmat_rank`（ℚ 上高斯）與 `@cyclic.rank_q`（F_p 上高斯、三質數取最大）
  在 6 個樣本矩陣上完全一致；`rmat_to_int` 先通分成整數矩陣（共同分母 = 最小公倍數）。

  三個套件互為見證（不是同一個函式庫算兩次，而是**兩套獨立的消去法**）。

## §9 成本與邊界

| 項目 | 上限 | 理由 |
|---|---|---|
| μ_n／ℚ/ℤ | n ≤ 16（T73）、n ≤ 12（T74／T75） | 可分性檢核是 O(n²·m) 的重複加法 |
| Φ_n／ℚ(ζ_n) | n ≤ 20 | 整係數多項式次數 φ(n) ≤ 8；σ_k 矩陣 φ(n)×φ(n) |
| 伽羅華群 | n ∈ {3,4,5,7,8,9,10,12} | 需 (ℤ/n)^× 不太大，且 φ(n) ≤ 4 |
| 跡／Ramanujan | n ≤ 20 | 同上 |
| 近似單位元 | N = 5、n = 0..4 | 展示閉式即可，不做規模測試 |

**界外**：無窮維 C*-代數的近似單位元（不可枚舉）、連續群的 C*_r G、
以及「自由同倫不變性」在無么代數上的 K₁ 版本（需穩定化與 Bott 週期性的完整機器）——
這些都不在本套件宣稱的範圍內；B0010 的界外清單（BC1–BC8）另有登記。
