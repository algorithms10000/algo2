## §B1 樣本代數與公理（T51／T51b）

**D-C1**：`FdAlg{name, dim, unit_vec, aug, mult}`。`mult[(i·d+j)·d+k]` 是 e_i e_j 的第 k 個座標。

**兩個關鍵的一般化**（BUG-24 的教訓）：

1. **單位是向量不是索引**。M_n(ℂ) 的單位是 Σ_i E_ii、k ⊕ k 的單位是 e₀ + e₁。
   把單位寫成「基底元素 0」會讓 Connes 算子的前插算子 s 錯掉，
   於是 bB + Bb = 0 在 M₂(ℂ)、k ⊕ k 上失敗。
2. **增廣是向量不是係數**。ℂ[G] 的增廣是「所有係數和」，k[x]/(x^m) 的是「常數項」，
   M_n(ℂ)（n ≥ 2）**沒有**增廣。`alg_aug_ok` 以 ε(1) = 1 與 ε(ab) = ε(a)ε(b) 兩條同時檢驗。

**T51**：8 個樣本（k、k⊕k、k[x]/x²、k[x]/x³、M₂(ℂ)、ℂ[ℤ/3]、ℂ[S₃]、ℂ[D₈]）的單位與結合律全真。

**T51b（負控制）**：把 k[ε]/(ε³) 的 x·x² = x³ = 0 改成 x·x² = 1（而 x²·x 仍為 0），
結合律**必須**失敗。這一條排除「T51 恆真」的可能。
（附帶的教訓：2 維交換代數 x² = α + βx 永遠結合，所以負控制必須用 3 維。）

## §B2 桶複體與 Connes 算子（T53）

**D-C2**：C_n = A^{⊗(n+1)}，b_n = Σ_{i<n}(−1)^i d_i + (−1)^n d_n。

**D-C3**：Connes 算子 B_n = (1 − t_{n+1})·s·N_n，其中

* N_n = 1 + t_n + t_n² + ⋯ + t_n^n（範數），
* s(x) = u ⊗ x，**u = Σ_k u_k e_k 是單位的座標向量**（BUG-24），
* t_n 是循環置換 t_n(a₀⊗⋯⊗a_n) = a_n⊗a₀⊗⋯⊗a_{n−1}。

**T53**：逐度檢驗 b_n∘b_{n+1} = 0、b_{n+1}B_n + B_{n−1}b_n = 0、D_n∘D_{n+1} = 0。
度數上限由成本決定（§B9，例如 ℂ[D₈] 只到 D² 的 n = 1：b₄ 是 4096×32768 的矩陣，會吃光記憶體）。

**定理（循環算子的階）**：t_n^{n+1} = id（`check_tau_order`，n = 0..3）。這是 λ-複體良定義的基礎。

## §B3 Hochschild 同調（T52）

**定義**：HH_n = ker b_n / im b_{n+1}，於是有

    dim HH_n = dim C_n − rank b_n − rank b_{n+1}.

**T52**：dim HH₀ 的兩條算式相等——

* `hh0_by_commutators`：dim A/[A,A]（交換子子空間的**餘維**，由 rank 算出）；
* `hh_dim(a, 0)`：混複體的度 0 同調（完全不同的矩陣）。

8 個樣本全同：1、2、2、3、1、3、3、5。

**實測值**（`-- cyctable`）：

| 代數 | HH₀ | HH₁ | HH₂ | HH₃ | HH₄ | HH₅ |
|---|---|---|---|---|---|---|
| k | 1 | 0 | 0 | 0 | 0 | 0 |
| k ⊕ k | 2 | 0 | 0 | 0 | 0 | — |
| k[x]/x² | 2 | 1 | 1 | 1 | 1 | — |
| k[x]/x³ | 3 | 2 | 2 | 2 | — | — |
| M₂(ℂ) | 1 | 0 | 0 | 0 | — | — |
| ℂ[ℤ/3] | 3 | 0 | 0 | 0 | — | — |
| ℂ[S₃] | 3 | 0 | 0 | — | — | — |
| ℂ[D₈] | 5 | 0 | 0 | — | — | — |

兩點值得記錄：k[x]/x^m 的 HH₁ = m − 1（= dim Ω¹，HKR 的可算情形），HH_n = m − 1（n ≥ 2）
（此代數不光滑，Hodge 分解**不適用**，所以不能拿 HKR 去「驗證」高階項——這正是必須實算的理由）。

## §B4 混複體與循環同調（T54）

**D-C4**：混合複體 (C_*, b, B)，總複體

    Tot_n = ⊕_{m ≤ n, m ≡ n (mod 2)} C_m,   D = b + B,   HC_n = H_n(Tot).

**實作要點（BUG-21 的教訓，R10 版）**：總複體按**奇偶分層**求和，不是「連續塊」。
連續塊偏移（Tot_n = Tot_{n−1} ⊕ C_n 形式的索引）在 n ≥ 3 會越界並在 wasm 上只留下
`RuntimeError: unreachable`（沒有任何行列資訊）。

## §B5 λ-複體與「兩條路徑」定理（T54、T55）

**D-C5**：C^λ_n = C_n / im(1 − τ_n)，微分由 b 誘導（因 b(1−τ) = (1−τ)b′，誘導良定義）。

**定理 T54（兩條路徑）**：HC_n = H_n(C^λ) = H_n(Tot(b,B))，8 個樣本、逐度 0..上限全同。

| 代數 | HC₀ | HC₁ | HC₂ | HC₃ |
|---|---|---|---|---|
| k | 1 | 0 | 1 | 0 |
| k ⊕ k | 2 | 0 | 2 | 0 |
| k[x]/x² | 2 | 0 | 2 | 0 |
| k[x]/x³ | 3 | 0 | 3 | 0 |
| M₂(ℂ) | 1 | 0 | 1 | 0 |
| ℂ[ℤ/3] | 3 | 0 | 3 | 0 |
| ℂ[S₃] | 3 | 0 | 3 | — |
| ℂ[D₈] | 5 | 0 | 5 | — |

**T55（負控制，BUG-22）**：若把循環算子取成**有符號**的 λ_n = (−1)^n t_n，
同一個「商掉 1 − λ」的公式在 k 的 n = 2 給 0（真值 1），在 k ⊕ k 的 n = 3 甚至給 **−1**。
負維度是「誘導微分不滿足 b̄² = 0」的症狀：`b(1−λ) = (1−λ)b′` 只在**無符號** τ 成立。
這條負控制留在程式裡（`hc_dim_lambda_signed`），確保 T54 不是恆真。

## §B6 結構定理：半單、Morita、加法性、群代數（T56–T59）

**T56**：A ≅ ⊕_{i=1}^{c} M_{d_i}(ℂ) ⇒ HH_n = 0（n ≥ 1）、HC_{2k} = c、HC_{2k+1} = 0。
M₂(ℂ)（c = 1）、ℂ[ℤ/3]（c = 3）、ℂ[S₃]（c = 3）、ℂ[D₈]（c = 5）全部命中。
——注意這是**預測**：程式完全不知道「單模個數」，它只算矩陣的秩。

**T57**：Morita 不變性 HH_n(M₂(ℂ)) = HH_n(ℂ)、HC_n(M₂(ℂ)) = HC_n(ℂ)（n = 0..3）。

**T58**：直和的可加性（ℂ ⊕ k[x]/x²，n = 0..4 逐度相加）。

**T59**：dim HH₀(ℂ[G]) = 共軛類個數，且 HH_n = 0（n ≥ 1）。
共軛類由 **Cayley 表暴力算出**（`group_conjugacy_classes`），與代數算出的 HH₀ 對撞：
ℂ[ℤ/3] → 3、ℂ[S₃] → 3、ℂ[D₈] → 5。
（這裡順帶得到群同調的退化：H_n(G;ℂ) = 0，n ≥ 1，因為 ℂ[G] 半單。）

## §B7 內部張量積（T61／T61b）與外部張量積（T60）

**D-C6**：A-雙模 M 由左右作用矩陣給出：`left[k·dim+i][p]` = e_k·m_i 的第 p 座標。

**定義（共端）**：M₁ ⊗_A M₂ = (M₁⊗M₂) / ⟨ (e_k m_i)⊗n_j − m_i⊗(e_k n_j) ⟩，
故 **dim(M₁⊗_A M₂) = dim M₁·dim M₂ − rank(關係矩陣)**（關係矩陣有 dim A·dim M₁·dim M₂ 列）。

**定義（內部 Hom）**：Hom_{A,A}(M₁, M₂) = {f : f(e_k m_i e_l) = e_k f(m_i) e_l}，
維度 = dim M₁·dim M₂ − rank(約束矩陣)。

**T61（三條結構定理）**

* **X1 單位**：dim(A ⊗_A A) = dim A；若 A 增廣，dim(A ⊗_A k_ε) = dim(k_ε ⊗_A A) = 1。
* **X2 共端 ＝ HH₀**：把 A 看成 Aᵉ = A ⊗ A^op 的雙模（α·m = amb、m·α = bma），
  則 **dim(A ⊗_{Aᵉ} A) = dim A/[A,A]**。8 個樣本全同（含 M₂(ℂ)：1、ℂ[S₃]：3）。
* **X3 伴隨**：dim Hom_{A,A}(A, A) = dim Z(A) = M^A（不變量空間），兩條算式對撞。
  M₂(ℂ) 給 1（中心是純量）、ℂ[S₃] 給 3（類和）、交換代數給 dim A。

**T61b（負控制）**：零作用「模」不滿足 `bimod_ok`（單位元不作用為恆等），
且 A ⊗_A M₀ = 0 ≠ dim M₀ —— X1 的成立**依賴么性**，不是恆真。

**T60（外部張量積）**：A ⊗_k B 上

* dim HH₀(A⊗B) = dim HH₀(A)·dim HH₀(B)；
* 半單時 HC_{2k}(A⊗B) = HC_{2k}(A)·HC_{2k}(B)（k = 0,1）；
* 實測：k²⊗k²（4 = 2·2）、M₂(ℂ)⊗k（1 = 1·1）、ℂ[ℤ/3]⊗ℂ[ℤ/2]（6 = 3·2）。

## §B8 漸新態射（T62）

對有限群 G，Baum–Connes 裝配映射 μ: K_*^G(EG) → K_*(C*_r G) 是同構，
在度 0 的等價敘述是「表示環秩 = 共軛類個數」。本輪把它落成四支可執行映射：

| 代號 | 映射 | 可執行的等式 | 檢核 |
|---|---|---|---|
| ASForget | 忘記（SBI 的 I 映射，度 0） | dim HH₀ = dim HC₀ | T62a（8 樣本） |
| ASIndex | 指數／秩 | 共軛類個數（Cayley 表暴力）= dim HH₀(ℂ[G]) | T62b（3 群） |
| ASBott | Bott 週期性 | HC_n = HC_{n−2}（n ≥ 2，6 樣本） | T62c |
| ASAssembly | 裝配映射（正度數同構） | HH_n = 0（n ≥ 1）、HC_{2k} = 共軛類、HC_{2k+1} = 0 | T62d |

**誠實邊界**：這四支是「樣本代數上的秩級陳述」，不是無窮維 C*-代數的裝配映射本體
（本工程的 K-理論在 B0006 是有限生成 Abel 群片段，見 `kk/README.md` 的界外清單 O1–O6）。
把 ASIndex 的秩與 B0006 的 K₀ 對接留給下一輪（Dev.txt R10 → R11）。

## §B9 成本表與度數上限

chain_size(d, n) = d^{n+1}，秩的計算是 O(min²·max)。實際上限（寫在 `cyclic_samples` 與 `axiom_bounds`）：

| dim | 樣本 | HH/HC 度數上限 | b²/bB/D² 上限 | 理由 |
|---|---|---|---|---|
| 1 | k | 5 | 5 / 4 / 4 | C₆ = 1 |
| 2 | k⊕k、k[x]/x² | 4 | 4 / 4 / 3 | C₅ = 64 |
| 3 | k[x]/x³、ℂ[ℤ/3] | 3 | 3 / 3 / 3 | C₄ = 243 |
| 4 | M₂(ℂ) | 3 | 3 / 3 / 3 | C₄ = 1024 |
| 6 | ℂ[S₃] | 2 | 2 / 1 / 2 | C₃ = 1296，C₄ = 7776 |
| 8 | ℂ[D₈] | 2 | 1 / 1 / 1 | C₃ = 4096，C₄ = 32768（1 GB，禁止） |

**秩的兩套演算法（T63）**：

* `rank_q`：F_p 上高斯消去（p = 2³¹−1、2147483629、2147483587，取最大值）。
* `rank_exact`：BigInt 整數消去 + 每列 gcd 歸一（無任何除法假設）。

兩者在樣本的所有小條邊矩陣上逐一相同（T63）。

**BUG-23（已修，不得回退）**：Bareiss 分數自由消去在「跳過零欄」後**整除性失效**
（81×243 的 b₄ 出現 231 次非整除），算出 rank 64 而真值 63，於是 HC/HH 出現負維度。
「精確算術」不等於「正確」——必須有第二套獨立演算法對撞。
