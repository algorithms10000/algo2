## 0. 這一輪要回答的兩個問題

### 0.1 超立方體網絡群的「完整刻劃」

`工程內容2.md` 名詞群裡的「**超立方體網絡群**」在 B0005 只被當成**圖**處理過（T31：生成樹數 τ(Q_n)、
Laplacian 的不變因子），群的部分完全沒做。而「完整刻劃」與「部分性質」是兩件不同的事：

| 只有部分性質（玩具） | 完整刻劃（本輪） |
|---|---|
| 造得出 2ⁿ·n! 個自同構（候選 ⊆ Aut） | 還要證 **Aut ⊆ 候選**：窮舉全部自同構，逐元素與候選**比對相等** |
| 「Q_n 看起來對稱」 | 給出群結構 Aut(Q_n) ≅ 𝔽₂ⁿ ⋊ S_n，並驗**核、商、穩定子、共軛類**四層 |
| 對 n = 3 驗一驗 | 對 n = 1..4 全驗，並把小 n 的退化（Q₁ = K₂、Q₂ = C₄ = D₈）**另立邊界檢核** |

本輪給出的完整刻劃是：

```
Aut(Q_n) = { v ↦ π(v) ⊕ b  :  π ∈ S_n, b ∈ 𝔽₂ⁿ } ≅ 𝔽₂ⁿ ⋊ S_n ≅ C₂ ≀ S_n ,   |Aut(Q_n)| = 2ⁿ·n!
```

三條獨立路徑固定它：**（i）回溯窮舉**、（ii）**由上而下生成候選**、（iii）**方向映射 + 平移**（半直積分解）。
三者兩兩相等，才叫刻劃。

### 0.2 KK 的界外部份

B0006 的 **A-K1 可判定性公理**當時只是一句規定：「KK 的陳述必須附適用類別，界外不得綠燈」。
本輪把它做成**可執行的東西**：界外的每一項都必須寫出

1. **為何界外**（引用哪一條失效的定理）、
2. **界內的截面**（我們到底算了哪一塊）、
3. **可計算見證**（真數字或真反例，否則「界外」只是免責聲明）。

於是界外不是「沒做」，而是「**做了、並且說清楚做到哪裡、並用數字標出界線在哪**」。
最有代表性的一條是自由積：

> **K₁(A * B) = K₁(A) ⊕ K₁(B)**（可加）　但　**K₀(A * B) ≠ K₀(A) ⊕ K₀(B)**（不可加）。
> 前者與 Pimsner–Voiculescu 的 K₁(C*_r(𝔽_n)) = ℤⁿ 相符；後者給出可計算反例：可加性預測 ℤⁿ，實際是 ℤ。

## 1. 公理（本輪新增）

**A-H1（兩向刻劃公理）** 宣稱「Aut(G) = X」必須同時給出 **X ⊆ Aut(G)**（候選全集由生成元閉包造出）
與 **Aut(G) ⊆ X**（窮舉全部自同構後逐元素比對），只給一側不算刻劃。

**A-H2（退化邊界公理）** 小參數的退化物件（n ≤ 2 的超立方體、n = 1 的摺疊、n = 1 的邊置換核）
必須**另立正面檢核**，不得因為「公式還成立」就跳過，也不得靜默刪除。

**A-H3（作用域公理）** 講「穩定子」必須指明作用在哪個集合上（頂點／邊／方向），
不得用「固定頂點 0」冒充「固定邊 {0,1}」（BUG-19 的教訓）。

**A-K5（界外可檢核公理）** 界外的每一項都必須有 `reason`、`inside_part`、`witness` 三個非空欄位，
且 `verdict` 只能是「界外」或「界內截面」；缺一項即判不合規（T48 就是這條的執行檔）。

## 2. 定義

**D-H1（超立方體圖 Q_n）** V(Q_n) = 𝔽₂ⁿ（以 0..2ⁿ−1 的位元串表示），
x ~ y ⟺ 漢明距離 d(x, y) = 1。

**D-H2（座標置換 π 的作用）** 對 π ∈ S_n，`permute_bits(v, π) = Σ_i bit_i(v)·2^{π(i)}`，
即「第 i 位搬到第 π(i) 位」。

**D-H3（平移）** 對 b ∈ 𝔽₂ⁿ，`translate(v, b) = v ⊕ b`（位元 XOR）。
平移群 T = {v ↦ v ⊕ b} ≅ 𝔽₂ⁿ。

**D-H4（候選群）** 由上而下預測的自同構群

```
Cand_n = { v ↦ permute_bits(v, π) ⊕ b : π ∈ S_n, b ∈ 𝔽₂ⁿ },   |Cand_n| = 2ⁿ·n!
```

本輪**不除重**地生成它（|Cand_n| = 2ⁿ·n! 本身就印證了「(π, b) ↦ 該映射」是單射，見 P-H2）。

**D-H5（回溯窮舉）** 以 **BFS 序**（先按漢明重量、再按數值）走訪頂點，
依序為每個頂點指定像，並用「與所有已定像的鄰接性必須一致」剪枝。
BFS 序的關鍵性質：第 k 步之前已定的像包含**整個球 B(0, k−1)**，故剪枝極強（A45）。

**D-H6（方向映射）** 對 σ ∈ Aut(Q_n) 與座標 i，令 e_i 為第 i 個標準基向量。
σ 把邊 {0, e_i} 送到邊 {σ(0), σ(e_i)}，該邊決定唯一方向 π(i)（相差的那一個位元）。於是

```
π = direction_map(σ) ∈ S_n ,   π(i) = 「σ(0) 與 σ(e_i) 相差的位元」
```

**D-H7（邊置換）** 邊集 E(Q_n) 有 |E| = n·2^{n−1} 條；σ 誘導 φ(σ) ∈ Sym(E)，φ(σ)({a,b}) = {σ(a), σ(b)}。

**D-H8（摺疊）** `fold_vertex(n, x) = x mod 2^{n−1}`（丟掉最高位）：Q_n → Q_{n−1}。

**D-H9（界外記錄）** `ScopeItem { id, title, reason, inside_part, witness, verdict }`，
`verdict ∈ {界外, 界內截面}`（A-K5）。

## 3. 命題與引理

**P-H1（漢明 = 圖距離）** d_Qn(x, y) = d_H(x, y)。
*證*：⊕ 平移保距離，故 d(x,y) = d(0, x⊕y) = popcnt(x⊕y)；而 0 到 w 的最短路恰是逐位翻轉，長度 popcnt(w)。
程式上以 **BFS 距離** 獨立算出再與漢明比對（T44）。

**P-H2（候選的單射性）** (π, b) ↦ [v ↦ π(v) ⊕ b] 是從 S_n × 𝔽₂ⁿ 到 (𝔽₂ⁿ)^{𝔽₂ⁿ} 的單射。
*證*：b = 該映射在 0 的值；π 由它在標準基向量上的作用（即各方向）還原。故 |Cand_n| = 2ⁿ·n!。

**P-H3（候選 ⊆ Aut）** Cand_n ⊆ Aut(Q_n)。
*證*：π 置換座標保漢明距離、⊕b 保漢明距離，故 v ↦ π(v) ⊕ b 保「漢明距離 = 1」。

**P-H4（核 = 平移）** 對 σ ∈ Aut(Q_n)：direction_map(σ) = id ⟺ σ 是平移。
*證*：(⇐) 平移把 e_i 送 e_i，方向不變。(⇒) 若 σ 使每個方向 e_i 映到同方向 e_i，
則由連通性沿 BFS 樹歸納得 σ(v) = σ(0) ⊕ v。程式上由 T43 對 n = 1..4 逐一驗證兩側。

**P-H5（邊置換是同態）** φ: Aut(Q_n) → Sym(E)，φ(σ∘τ) = φ(σ)∘φ(τ)，且對 n ≥ 2 是單射。
*證*：兩點 a, b 相鄰 ⟺ {a,b} ∈ E；若 φ(σ) = id 則 σ 固定每一條邊，
而 n ≥ 2 時 Q_n 的邊集決定頂點集（每條邊的兩端就是它自己），故 σ = id。
n = 1 時唯一一條邊 {0,1} 被「交換兩端」的自同構固定 ⇒ ker φ = ℤ₂（A-H2 的退化邊界）。

**P-H6（摺疊的纖維結構）** fold: Q_n → Q_{n−1} 是滿圖同態；
每個纖維 fold⁻¹(y) = {y, y + 2^{n−1}} 恰是一條邊；Q_{n−1} 的每條邊恰有 2 條原像。
*證*：位元串去掉最高位後，兩點相差單位向量 ⟺ 原像相差單位向量（最高位那條對應「纖維內的邊」）。

## 4. 定理（T41–T50）

### T41　完整刻劃：Aut(Q_n) = Cand_n（n = 1..4）

對 n = 1, 2, 3, 4，**回溯窮舉出的自同構集合與由上而下生成的候選集合逐元素相等**：

| n | \|V\| | \|Aut\|（窮舉） | \|Cand\|（預測） | 2ⁿ·n! | 集合相等 |
|---|---|---|---|---|---|
| 1 | 2 | 2 | 2 | 2 | ✓ |
| 2 | 4 | 8 | 8 | 8 | ✓ |
| 3 | 8 | 48 | 48 | 48 | ✓ |
| 4 | 16 | 384 | 384 | 384 | ✓ |

**負控制**：Q₃ 上「交換頂點 1 ↔ 2、其餘固定」是雙射、卻破壞鄰接（1~5 是邊、2~5 不是），
故 **不在** 窮舉結果中。三項必須是「是／是／否」——這一條保證 T41 不是恆真。

落點：`check_full_characterization`、`check_nonaffine_rejected`。

### T42　群階與軌道—穩定子

|Aut(Q_n)| = 2ⁿ·n!，且對頂點與邊分別用軌道—穩定子定理交叉檢核：

```
|Aut| = |V| · |Stab(0)| = 2ⁿ · n!        （|Stab(0)| = n!，即座標置換群）
|Aut| = |E| · |Stab({0,e_1})| = n·2^{n−1} · 2(n−1)!
```

實測：Stab(0) = 1, 2, 6, 24（n = 1..4）；邊穩定子 2, 2, 4, 12。
兩個乘積都等於群階，這是「可遷 + 穩定子」的機械印證。

落點：`check_order_formula`。

### T43　方向映射 Aut(Q_n) → S_n：良定義、同態、核 = 𝔽₂ⁿ

`direction_map` 對 n = 1..4 的**每一個**自同構都回 `Some(π)`，且

```
(i)  π 確為 0..n−1 的雙射；
(ii) π(σ∘τ) = π(σ)∘π(τ)            （同態）
(iii)|ker π| = 2ⁿ，且 ker π 的每個元素都是平移（P-H4）；
(iv) |Aut| / |ker π| = n!            （第一同構定理 ⇒ Aut/T ≅ S_n，Aut = T ⋊ S_n）
```

實測 |ker π| = 2, 4, 8, 16，商群階 = 1, 2, 6, 24 = n!。
程式上先為每個元素算一次 π，再驗同態（A48 的複雜度理由，見 BUG-20）。

落點：`check_direction_map`。

### T44　Cayley 刻劃與距離正則性

Q_n ≅ Cayley(𝔽₂ⁿ, {e_1,…,e_n})：**x ~ y ⟺ x⊕y 是標準基向量**。
並且：圖距離 = 漢明距離（P-H1）、n 正則、|E| = n·2^{n−1}、直徑 n、連通、平移群 T 正則
（|T| = 2ⁿ = |V|、只有 id 固定 0、0 的軌道是全部）。

| n | \|E\| = n·2^{n−1} | 直徑 | 正則度 | 距離 = 漢明 | T 正則 |
|---|---|---|---|---|---|
| 1 | 1 | 1 | 1 | ✓ | ✓ |
| 2 | 4 | 2 | 2 | ✓ | ✓ |
| 3 | 12 | 3 | 3 | ✓ | ✓ |
| 4 | 32 | 4 | 4 | ✓ | ✓ |

落點：`check_cayley`。

### T45　摺疊 Q_n → Q_{n−1}，與 n ≤ 2 的退化邊界

(a) 對 n = 2, 3, 4：`fold` 是滿同態、纖維大小 2、Q_{n−1} 每條邊**恰有 2 條**原像（P-H6）。
(b) 退化邊界（A-H2）：

| 物件 | 群 | 實測 |
|---|---|---|
| Q₁ = K₂ | Aut = S₂ = ℤ₂ | \|Aut\| = 2、\|E\| = 1、直徑 1 |
| Q₂ = C₄ | Aut = D₈ | \|Aut\| = 8、\|E\| = 4、無三角形、共軛類 5、階數分布 1¹2⁵4² |
| Q₁ → Q₀ | 退化 | Q₀ 是單點，唯一一條邊塌成一點 ⇒ `fold_is_hom(1) = false`（正面斷言） |

落點：`check_folding`、`check_degenerate_boundary`。

### T46　邊置換群

φ: Aut(Q_n) → Sym(E) 是同態（P-H5）；邊集在 Aut 下**可遷**（一條邊的軌道 = 全部 |E| 條）；
核在 n ≥ 2 時平凡、n = 1 時為 ℤ₂。

| n | \|E\| | 邊軌道 | \|ker φ\| |
|---|---|---|---|
| 1 | 1 | 1 | 2（例外） |
| 2 | 4 | 4 | 1 |
| 3 | 12 | 12 | 1 |
| 4 | 32 | 32 | 1 |

落點：`check_edge_action`。

### T47　共軛類個數 = Σ p(k)·p(n−k)

Aut(Q_n) ≅ C₂ ≀ S_n 的共軛類與「**一對無序分割** (α, β)，|α| + |β| = n」一一對應，於是

```
#Conj(C₂ ≀ S_n) = Σ_{k=0}^{n} p(k)·p(n−k)
```

實測與公式：2, 5, 10, 20（n = 1..4），且各類大小之和 = 群階（Burnside 覆蓋檢核）。
p(k) 直接借用 B0006 的無序分割計數（`@kk.partitions`）——這是「**併攏**」這個動詞的落地。

落點：`check_conjugacy_formula`、`paired_partition_count`。

### T48　界外清單的合規性與 kind = 0 的明示

界外清單 O1–O6 的每一項都有非空的 `reason`／`inside_part`／`witness`，`verdict` 合法；
**純界外 2 項**（O3 min/max、O5 非有限生成）。

最關鍵的一條：「不決定」必須可檢核。取 K₀ = ℤ、K₁ = ℤ/2 的 A 與 B：

```
Hom = ℤ ⊕ ℤ/2 ,  Ext¹ = ℤ/2 ,  kind = 0
UCT 只給：0 → ℤ/2 → KK → ℤ ⊕ ℤ/2 → 0
⇒ KK 可能是 ℤ ⊕ ℤ/2 ⊕ ℤ/2，也可能是 ℤ ⊕ ℤ/4（兩者都符合 UCT）
```

程式把這兩個值都算出來並斷言它們**不相等**——這才是「未決定」的內容。

**負控制**：缺 `witness` 或缺 `verdict` 合法的記錄必須被判不合規（否則 T48 恆真）。

落點：`check_outside_manifest`、`check_outside_negative_control`、`scope_item_compliant`。

### T49　自由積 K-群：K₁ 可加、K₀ 不可加

```
K₁(A * B) = K₁(A) ⊕ K₁(B)          （Cuntz 的可加性定理）
K₀(A * B) ≠ K₀(A) ⊕ K₀(B)          （沒有一般公式）
```

以 C*_r(𝔽_n) = C(S¹) * … * C(S¹)（n 份）驗證：

| n | K₁ 可加預測 | K₁ 登記值（Pimsner–Voiculescu） | K₀ 可加預測 | K₀ 登記值 | 可加性 |
|---|---|---|---|---|---|
| 2 | ℤ² | ℤ² | ℤ² | ℤ | K₁ ✓、K₀ ✗ |
| 3 | ℤ³ | ℤ³ | ℤ³ | ℤ | K₁ ✓、K₀ ✗ |
| 4 | ℤ⁴ | ℤ⁴ | ℤ⁴ | ℤ | K₁ ✓、K₀ ✗ |

所以本輪只把 **K₁ 的可加性**放進界內，K₀ 的自由積計算明示界外（O4）。

落點：`check_free_product_k`、`free_product_k1`、`free_group_cstar_kpair`。

### T50　Künneth 的界內截面

對 bootstrap 樣本（有限維代數、C(S¹)）驗證

```
K_n(A ⊗ B) = ⊕_{i+j=n} K_i(A) ⊗ K_j(B)  ⊕  ⊕_{i+j=n−1} Tor(K_i(A), K_j(B))
```

實測：

| 樣本 | 計算結果 | 交叉檢核 |
|---|---|---|
| M₂ ⊗ M₃ | K₀ = ℤ、K₁ = 0 | = M₆ 的 K-群；且 dim(M₂)·dim(M₃) = dim(M₆) = 6 |
| M₂ ⊗ C(S¹) | K₀ = ℤ、K₁ = ℤ | = M₂(C(S¹)) 的 K-群 |
| Tor(ℤ/2, ℤ/2) | ℤ/2 | 撓項必須出現，否則公式缺一項 |
| Tor(ℤ/2, ℤ/3) | 0 | 互質 ⇒ 無撓（負控制） |

非核情形（C*_r(𝔽₂) ⊗ C*_r(𝔽₂)、min/max 分歧）**只登記不宣稱**（O3）。

落點：`check_kunneth_inside`、`fga_tensor`、`fga_tor`、`kunneth_kpair`。

對照：C₂ ≀ S₂ = D₈ 的 5 個共軛類、階數分布 1·5·2 —— 與古典結果一致；
共軛類總數 2, 5, 10, 20 正是「一對分割」序列（A000712 的前四項）。

